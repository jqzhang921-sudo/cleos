一个安卓原生（Kotlin + Jetpack Compose）的陪伴聊天 App，界面是自己写的液态玻璃。
除了和 TA 聊天（自己填 API），也能写日记（可以贴图）、记待办。数据都只存在手机上。

- **聊天**：OpenAI 兼容接口（DeepSeek / 智谱 / OpenAI / 硅基流动 / Kimi / OpenRouter……），流式输出、可停止、失败可重试。可以有多段对话。
  智谱默认 GLM-5.3-Flash（便宜，能看图）；它的接口不列模型，「测试并列出模型」给的是文档里写的那几个。
  能发图片（一次最多 4 张）：模型要能看图；看不了图的模型会自动只发文字，并在聊天里说一声。
  气泡和输入框里的字默认 15，「设置 › 聊天」里能换成 14 / 16 / 17；行高是字号的 1.6 倍（只加在行与行之间，一行的气泡不会变高），
  气泡最宽占屏幕七成，内边距 12×8。
  语音默认只显示播放按钮和时长，点“查看文字”展开转写；设置 › 聊天可开启“默认展开语音文字”。
  设置 › 外观可分别选择我与当前 TA 的气泡主题：默认玻璃、雾蓝小困、奶桃小闹、透明留白。
  主题用于文字、流式回复与语音，装饰独立绘制并保持固定尺寸，选择随备份保存。
  气泡默认紧凑留白，外观页可选紧凑 / 标准 / 宽松或分别细调左右、上下留白，并实时预览。
  “编辑装饰”可分别调整小脸和星点的大小、四角位置与显示状态，并恢复默认装饰；随备份保存。
  气泡调节集中在设置 › 外观 › 气泡实验室，上方预览固定，下方控件独立滚动；可切换双方和短句 / 长消息 / 语音。
  材质与背景支持玻璃 / 柔色、纯色 / 双色渐变，颜色、方向、不透明度和柔边可实时调节；配色按双方与主题分别保存。
- **消息操作**：长按可整条复制，也可进入「选择文字」拖动选区复制片段；聊天和工具详情中的 HTTP/HTTPS 链接可以直接打开。
  支持多选删除聊天及相关工具记录，删除记录不会撤销已经执行的操作；往上翻时可一键回到最新消息。
- **已保存的模型配置**：接口地址、模型和命名配置可保存并随时切换；Key 按接口地址加密保存在本机。
  编辑、切换服务选项都是草稿，只有保存或明确使用已保存配置才生效，返回不会因误触改变当前 TA 的模型。
- **朋友圈与话题**：你的动态页由所有 TA 共用，支持文字、最多 9 张图片、点赞、评论及回复具体的人；封面铺满，下面使用卡片玻璃材质。
  动态可转发为聊天卡片，由你选择与哪位 TA 聊。可以邀请 TA 看看正文或评论，作者不会回应自己的正文或评论。
  各 TA 可以独立开启「主动逛朋友圈」，默认关闭，有频率、每日上限和夜间免打扰；可以阅读互动，也可另选自动分享日常或资讯。
  「想看什么」可以多选猫猫宠物、旅行风景、美食厨房、科技数码、科学太空，或自填 RSS / Atom；TA 按兴趣选题，也可以保持安静。
  完成情况与后续计划见 [朋友圈计划](docs/MOMENTS_PLAN.md)，当前更新与验证边界见 [0.41.66 发布检查](docs/RELEASE_READY_0.41.66.md)。
- **电话和语音换个模型**：「模型」页下面的开关。打开后另填一个服务和模型（Key 一样跟着地址存），打电话时 TA 说的话、
  你发语音过去后 TA 回的那一条，由它来写；平时打字、主动找你、写信、前情提要还是原来那个。TA 自己想发的语音条不换：
  那段话在它打字回复时就写好了。地址和模型没填全时当没开。
- **好几个 TA**：每个 TA 有自己的名字、头像、性格和模型，各聊各的、各写各的日记，互相看不到。在主页顶上或聊天页的标题上切换、添加。
  你的日记和小秘密，对每个 TA 规矩都一样。Key 跟着接口地址存：同一个服务上的几个 TA 共用一个，填一次就够。
  性格在「设置 › 资料与性格」里点开单独一页写，最多 3 万字；每条消息都会带着它，写得越长，每次花的 token 越多
  （DeepSeek 这类会缓存不变的开头，重复的那部分便宜很多）。
- **分几条发**：TA 想分开说的时候，会一条一条地发（`send_message` 工具，一次调用一个气泡），像聊天软件里那样。
  模型直接回复文字也照常显示，所以不支持工具的模型最多是不拆开，不会不说话。
- **TA 能动手**：在聊天里说一声，TA 会调用工具去做：记待办、看清单、改日期、打勾，读你的日记（默认关着），写自己的日记，问你要小秘密，拿你发来的图或一个表情换自己的头像，查天气（open-meteo，不要 Key），
  查你在哪（默认关着；手机定位，地名先用手机自带的解析，没有就问 BigDataCloud，只在聊天中查）。
  做了什么在聊天里有一行小字。每项都能在「设置 › 能做的事」里关掉；模型不支持工具调用的，会自动不带工具，聊天照常。
- **闹钟**：你让 TA 定闹钟、计时，它交给手机自带的时钟 App（`set_alarm` / `set_timer`），到点由手机响，贪睡、关掉都在时钟里，
  和你自己定的一样。闹钟只认钟点（最近的那一次响）和按星期重复；更远的日子用日历。只在 Cleos 开在前台时能定：
  安卓不让后台的 App 打开别的 App，切走了它会照实说没设上。
- **日历**（默认关着，打开时要日历权限）：TA 能看你手机日历上的所有安排；你让它记的日程加在它自己建的「Cleos」日历里
  （本地的，不同步），可以带提醒，由手机日历到点提醒。它只能改、删自己加的，你的日程只能看。
- **日记**：文字和图片按写的顺序排，图插在光标处；边写边自动保存。TA 也有自己的日记，和你的写在同一个本子里，标着是 TA 写的（你能看，改不了）。
- **小秘密**：日记可以锁上。TA 知道有，但看不到标题和内容；想看会在聊天里发一张卡片问你，你点「给 TA 看」才给看这一次，日记还是锁着。
- **前情提要**：每次原样发给模型的是最近那几十条消息（「设置 › 聊天」里定多少）。更早的，TA 会在后台整理成一段前情提要，跟着每条消息带着，
  聊得再久也不会一下子忘掉前面的事。窗口一段一段地往前挪，中间每次请求的开头都一样，DeepSeek 这类有缓存的接口大多能命中。
  聊天里往上翻能看到分界的那一行，点开能看、能改。
- **深度思考**：每个 TA 可以单独开，回答前先想一想（DeepSeek、智谱认这个开关；不认的会自动照常回复）。
  智谱 GLM-5.3 起的模型关不掉思考（硬关请求会失败），关着时改成让它少想（`reasoning_effort: low`），不然每句都按最深的程度想。
- **等我说完再回复**：每位 TA 在「说话方式」里单独设置，最后一条消息后等 1、3、5 或 10 秒再开始回答，默认 3 秒。
  连发会重新计时；输入、录音和选附件时继续等，草稿最多额外等到最后发送后的 30 秒，语音转写完成后才回答。
- **还有句话**：每位 TA 单独开启，默认关闭。正常回复结束后等 30 秒、1 分钟或 3 分钟，再给 TA 一次决定是否补充的机会，也可以保持安静。
  开始输入或发新消息时取消，补充不会触发下一次补充。前台和后台共用一次机会，过时就跳过；即使没说话也会增加一次模型请求和 token 消耗。
- **想找你聊**：每位 TA 在「说话方式」里独立开启，默认关闭。偶尔约每 4–6 小时，自然约每 30–60 分钟，比较主动约每 10–20 分钟给一次机会；每天最多考虑 3、24、60 次（每次会请求模型，用工具时可能请求多轮）。
  首次聊天后生效；TA 自己决定聊什么、是否说话，也可以在所选间隔范围内规划下次什么时候再看看；你开始输入时取消旧安排，聊完重新安排。
  默认 23:00–08:00 免打扰，可以自选时段或关闭，时段只影响想找你聊。
  聊完至少留 15 分钟空闲，连续两轮主动消息没收到回复就先停下；当天考虑次数不会因重启、改档或开关重置。
- **主动消息记录**：在「说话方式」里查看最近的唤醒时间线。想找你聊、聊完补充、定时记事、招呼和主动逛朋友圈的结果都可查看。
  记录模型请求尝试轮数和工具名称，区分「模型选择安静」与「未请求模型就被规则跳过」；不展示隐藏思考、工具参数或日记正文，不额外请求模型。
- **发语音**：按住输入框右边的话筒说话，松开就发，上滑取消。语音先由一个转文字的服务（OpenAI 那种 `/audio/transcriptions`：
  硅基流动 SenseVoice、智谱、Whisper……在「设置 › 发语音」里选）转成文字，再给 TA；气泡能点开播放，下面附着转出来的字。
- **语音条**：TA 想用声音说的时候发语音条（`send_voice`），你能听也看得到字。在「设置 › TA 的声音」里选一个平台，
  每个平台单独一栏，只要它的 Key 和一个音色：硅基流动（CosyVoice 的八个音色）、MiniMax（国内版 / 国际版，常用的八个音色，
  填好 Key 能列出全部音色）、Mossland（十五个公共音色，或者音色库里的 ID）、ElevenLabs（填好 Key 能列出自己的声音）、OpenAI，
  还有「其他接口」：兼容 OpenAI `/audio/speech` 的平台（比如中转站）填地址、模型和声音。能试听；合成不出来就改成文字发。
  （以前有一个用 MCP 工具合成的通用办法，没人弄得明白怎么填，去掉了；以前填过的硅基流动、Mossland、OpenAI 会自动换到各自那一栏。）
  戴着耳机听，语音条像贴在耳边说话，还会一边说一边挪：从一只耳朵绕到脑后到另一只、从脑后或面前靠到耳边，或者就待在一只耳朵边上（随机挑一种）。
  用的是 Neumann KU100 假人头在耳边 25 厘米起实测的头相关脉冲响应（近场 HRIR），距离不同，声音的样子就不同，
  不是只调左右音量。只在说话时挪，停顿里不动（不然下一句像是从一只耳朵跳到另一只）。
  第一次放一条时在手机上算（先按语音条的采样率重采样，再 1024 点一帧、半帧重叠地卷积），存在缓存里，之后直接放；
  外放照原样。开关在「TA 的声音」下面，默认开。（`ai/Binaural.kt`、`ai/EarVoice.kt`）
- **打电话**：聊天顶栏的电话按钮。响一会儿 TA 接起来先开口，之后你说完停一下（1.2 秒）它就接话；停到一半（0.6 秒）就先把你的话拿去转文字，等停够了字也差不多转好了。用的就是「发语音」的转文字服务
  和「TA 的声音」，两样都接好才能打。你说的话转成文字给模型；TA 的回复边写边按句子切开，一句一句合成、播放
  （这一句在念，下一句已经在合成），不用等整段写完才出声；屏幕上有字幕。
  两边轮流说：TA 说话时不听话筒（外放的声音会被当成你在说），点屏幕任意地方能打断它，存下来的是它真说出口的那部分。
  电话里不深度思考（等那么久像掉线了），也不给发消息、语音条、表情包、放歌这类工具；记待办、查天气、记忆这些照用。
  你说完没有，看的是声音比屋里的底噪高出多少：底噪在没人说话时跟着屋里变，一直响的声音（风扇、街上）算底噪不算人声。
  好一会儿（两分钟）没人说话，TA 会问一句还在不在，再过一分钟还没声音就挂了。挂断马上生效：还在路上的转文字、合成声音的请求当场掐掉。
  切到后台、锁屏照样通话（话筒类的前台服务，通知栏里能挂断）。挂了以后聊天里留一张通话卡片，点开看说了什么，也能删；
  说的话都在这段对话里，TA 记得，之后再打字聊它知道「电话挂了，打了几分钟」。声音不留，只留文字。（`ai/Call.kt`）
  做法参考了别人做的一个网页版 AI 语音通话的两篇说明（代码没用）。
- **表情包**：输入框右边的笑脸里是你自己的表情包：从相册加，起个名字、写一句图里是什么（TA 看不到图，是按名字认的），点一下就发。
  会动的（GIF、动图 WebP）原样存，在聊天里动三遍就停，点一下再动：一直动的话，玻璃底下整屏每帧都得重画。
  消息里的表情包只是几个字 `[[sticker:名字]]`，图不进请求：TA 发一张花的是这几个字的钱，看不了图的模型也知道你发了什么。
  「发表情包」开着（默认开，不需要模型支持工具）时，TA 的系统提示里有这份名单（名字和说明，最多 100 个），它会偶尔挑一张发；
  关着的话，你发的表情包按「发了一张表情包：名字，说明」讲给它听。改名后旧名字还记着，发过的消息照样显示；
  删掉的，发过它的地方变成「[表情包：名字]」。跟着备份走。
  做法参考了 [cute-chat-stickers](https://github.com/Anko3o/cute-chat-stickers) 的思路（那是网页的，代码没用）。
- **贴表情**：长按 TA 的消息，最上面一排表情点一个，贴在那条下面，再点一次拿掉。它不会让 TA 回话：
  你下一条消息发过去的时候，TA 才看到「对方给你说的「…」贴了 ❤️」，之后一直留在那条消息前面。
- **外部服务（MCP）**：「设置 › 外部服务（MCP）」里能接 MCP 服务（只支持 Streamable HTTP），TA 就能用它们的工具。填地址和 Token（`Authorization: Bearer`；
  key 写在地址里的也行），「测试连接」会列出它有哪些工具。调用前默认在聊天里弹一张卡片问你：允许 / 以后都允许 / 不允许；
  服务自己标了只读的工具不问。配置加密存在手机上，不进备份。
- **记忆**：TA 自己决定记什么（`memory` 工具：打开、记下、改、忘掉），分五类：关于你的四类（基本情况、在意的事、最近、相处方式）和关于它自己的。
  每条的一句摘要跟着每条消息带着，细节要用时才打开，所以记得再多，每轮也多花不了多少。每类最多 10 件事，每件最多 30 条细节；
  记满了 TA 会合并或删掉过时的。写信时细节一起带上，太多时每件只带最新的几条。主页「记忆」里能看、能改、能钉住
  （钉住的 TA 只能看），也能自己加一条。每个 TA 各记各的。
- **信**：每个 TA 和你一个信箱（主页上的「信」）。你写信寄出，TA 一定回；寄的时候选回信什么时候到：写好就到、一小时内、
  几个小时（1～6 小时，赶上夜里就等到早上 8～9 点）、明早 8～9 点，默认是上次选的。
  TA 也会不定期自己写来：默认隔至少 5 天（「设置 › 能做的事」的「写信」下面能改）、这段时间有话可写才写，没什么可写就不写；夜里写的等到早上才到。
  信只有你们俩看得到，聊天里提到信 TA 也接得上。
  信是提前写好、到点才出现的，不靠后台任务（很多手机会把后台掐掉）：App 回到前台时，该写的就写。寄到的时候发个通知。
- **主动找你**：聊天时 TA 可以给自己记一笔（`note_for_later`：想过一阵再说或再问的事、当时的情形、多久以后），
  比如你说去做饭了，它记下四十分钟后问问做得怎么样。到时候后台叫醒它，它看看这之间聊了什么，自己决定说、不说（SKIP）或者再推一次；
  说出来的进聊天记录，上面标「TA 自己想起来的」，同时发通知。叫醒它的是它自己记下的事，再加早晚各一次的招呼（见下），
  不会因为你没回、好久没聊来催你。它正在回你、或者你正在打字的时候，等一分钟再说；它主动说的两次都没回，就先不推了。
  通知只在你没看着这段聊天的时候发（在别的页面、别的 TA、App 在后台都算没看着）；打开聊天它也留着，划掉才走。
  同一段聊天里它主动说的，一条通知里都带着，直到你回话。
  醒来的时候它还能看到接下来一天的日程（开了日历的话）和没做完的待办，真用得上才顺带提一句。
  手机可能把后台任务往后拖，所以每一笔都会过期（按等的时长，30 分钟到 3 小时），过了时候就不说。
  每个 TA 一个开关，在「设置 › 说话方式」里，默认开；下面能看到记着几件事、算出来的作息、上次醒来说了什么或为什么没说。
- **早晚打个招呼**（也归「主动找你」那个开关）：从最近两周你发消息的时间，算出你一般几点开始找 TA、几点说最后一句
  （凌晨一点那句算前一天的；不到 5 天不算）。早上从平时开始说话前 20 分钟到之后两个半小时，隔一阵看一眼：
  手机亮着、解了锁才算醒了，今天已经来聊过就不打；晚上在平时最后一句前后，手机还在用、这会儿也没在聊，才会来道晚安。
  说不说、说什么由 TA 定，可以 SKIP；它也不知道是怎么看出你醒着的，不会说「看到你手机亮了」。每天早晚各最多一次，只有正在聊的那个 TA。
  平时中午以后才开始聊、或者晚上八点前就不聊了，对应的那一次就没有。
- **一起听歌**（「设置 › 能做的事」里的开关，默认关）：用平时的音乐 App 放歌（网易云、QQ 音乐、酷狗、Spotify 都行），不用登录任何音乐账号。
  只认一份音乐 App 的名单（`MusicApps`）：抖音、B 站这些放视频的也会向系统报「正在播放」，读了就会把视频文案当成歌发给 TA，
  所以名单外的一概不读，也不替它们暂停、切换。
  读的是每个播放器本来就告诉系统的「正在播放」（锁屏上的播放卡片就是这个），所以要开一次「通知使用权」；
  开关打开时直接跳到 Cleos 那一项。Cleos 拿到这个权限后马上把通知的连接断开，一条通知都不收，只读在放什么歌。
  从下载的 apk 装的，安卓 13 以上那个开关可能是灰的：先去应用信息右上角 ⋮ 里点「允许受限制的设置」（设置页有按钮带过去）。
  - 聊天页顶上一条小播放条：封面做成唱片，换一句歌词转一下（一直转的话整屏每帧都得重画，白耗电）；歌名、正唱到的那句歌词；
    能暂停、下一首，点其余地方打开那个播放器。
    放着的时候一直在，暂停后留 10 分钟。
  - 你每发一条消息，TA 都知道在放哪首、放到哪、唱到哪句（写在时间旁边，不进系统提示）；不用每首都点评。
  - 你让 TA 停一下、接着放、换一首，它用 `music_control` 直接切，切完知道换成了哪首。TA 自己醒来的时候没有这个工具。
  - 播放器自己给了歌词的，用它的：ColorOS 上 QQ 音乐、网易云、酷狗、酷我会把歌名、歌手和整首时间轴歌词写进
    `MediaMetadata["lyricInfo"]`（锁屏歌词读的就是这个）。开了车载/蓝牙歌词时，它们会把「歌名」一栏换成正在唱的那句、
    「歌手」一栏换成「歌名-歌手」，真正的歌名只在这里面，所以先读它。
  - 没给的，歌词来自 [LRCLIB](https://lrclib.net)（开源、免费、不要 key，国内直连能通），按歌长对上同一个录音版本
    （差 3 秒以内；没有就放宽到 8 秒），歌名里「(Explicit)」「(Live)」这类括号去掉再查。一首歌只问一次；
    回复最多等 4 秒，没等到的会接着查完存下，下一条消息就有；查失败了歇一分钟再查。只有繁体的歌词会按播放器写歌名的字转成简体。
  - 做不到的：让 TA 点一首歌自动开始放——网易云、QQ 音乐都不接安卓的「按歌名播放」。
- **TA 的小秘密**：TA 写日记时也可以上锁，只展示公开提示。点「问问 TA，能不能看」会跳到聊天预填一句询问，编辑后再发送。
  TA 可以拒绝、分享全文，或者只分享一段；也可以主动分享。摘录出现在聊天卡片和日记页，未分享的正文继续隐藏。
- **收藏**：聊天里长按消息可以收藏，文字、图片和双方的语音都能留下；「多选」勾几条，按原顺序合成一段，中间跳过的用省略号隔开。
  主页的「收藏」跟着当前 TA，各自分开。列表是玻璃摘录卡，点开按左右对话看，可以播放原语音、看图片、写备注，搜索原文和备注。
  收藏保存独立副本：删了原消息或原对话，留下的内容和声音仍在；原文还在时可以跳回去。收藏与备注不会自动发给模型。
  取消收藏可以撤销，随备份一起导出和恢复；删除一个 TA 时，其收藏也一起删除。通话详情可以收藏文字，通话本身不录音。
- **待办**：可加日期和备注，完成的收起来，长按删除可撤销。
- **从别的 App 搬过来**：在「设置 › 数据与备份」里选一个文件，四样都认：**角色卡**（一张新开一个 TA，文件里几张就开几个，
  别的东西都归第一个；PNG 图片卡也认，Operit 的卡和它整包备份的卡都认）、**世界书**（进那个 TA 的「设定」）、
  **记忆库**（关于你的事）、**历史聊天**（接成一个对话）；一个文件里有两样、三样也认得，
  都不认得的，还按老样子的记忆文件读（JSON、纯文本、Markdown，「名字: 内容」拆成两半）。
  记忆一类只记 10 件（每件每句话都跟着走），多出来的搬进「设定」里「搬来的记忆」那一本，要用才查。
  也认得 [phone-ai-assistant](https://github.com/jqzhang921-sudo/phone-ai-assistant) 导出的备份：那边的对话和它写的日记
  放进一个新的 TA，它记得的关于你的事写进这个 TA 的性格；图片（那边的备份里只有名字）和工具调用不带。
- **设定**：世界观、人物、地点这类，一段一条，在「设置 › 资料与性格」下面的「设定」里，世界书搬进来就是一堆这样的条目。
  它不跟记忆一样每句话都摆在 TA 眼前：最近的消息里只带一份目录（书名、标题、关键词），聊到相关的话时，TA 自己去查那一条，
  照原文说，书里几百条也不多花什么。开关在「能做的事 › 查设定」，单条的开关在「设定」页里。
- **主页**：你和正在聊的这个 TA 的头像、名字（头像从相册选，拖动缩放裁成圆的），认识的第几天（默认从第一句话算，可以改），聊过多少句、TA 写了多少篇日记。头像也可以放在聊天气泡旁边（「设置 › 聊天」里开）。
- **设置**：从「主页」右上角进（聊天、日记、待办页上不放，那几页的顶栏只留自己的事）。首页是一张目录，分三组：正在聊的 TA（资料与性格、设定、模型、说话方式，只改这个 TA）、所有 TA 共用（能做的事、TA 的声音、外部服务）、
  App（聊天、发语音、外观、数据与备份、关于）。每行写着现在的状态，点进去是单独一页；开关下面的说明默认只露一行，点一下看全文。
- **闪退记录**：Cleos 闪退时，出错的位置会记在手机上（哪个版本、什么手机、错在哪一行，不含聊天内容）。
  下次打开，「设置 › 关于」里能复制下来，发给做 App 的人。后台有件事没做成、App 没退出的（比如叫醒的时候那个 TA 正好被删了），
  另记一份「后台出错」，在同一个地方看：宁可少写一条记录，也不让后台的差错把 App 带走。
- **正在回复**：TA 写回复的时候，通知栏里有一条安静的「正在回你…」（无声、不进角标），写完就消失。
  它不是为了提醒，是让系统别在写一半的时候把 App 冻住——所以从回复一开始就挂着，而不是等人走开才立：
  走开那一刻正是这些手机冻进程的时候，服务请求递不到，安卓五分钟之内没等到 `startForeground` 就把 App 杀掉。
- **去蓝奏云看新版**：「设置 › 关于」里的按钮。蓝奏云时不时停掉一个域名（2026-10 停了 lanzouc.com，老版本里的按钮就一直卡在加载），
  所以按钮带着几个域名（`Releases.kt`），点的时候先查哪个还解析得到，打开那个；提取码自动复制。
- **请开发者喝杯奶茶**：「设置 › 关于」里一个微信收款码（头像和名字打了码，扫出来还是同一个码），能存到相册：
  同一台手机扫不了自己屏幕上的码，存下来再在微信「扫一扫」里从相册选。只放在这一处，App 别的地方不提。

## 液态玻璃是怎么做的

全在 `app/src/main/java/com/cleo/cleos/glass/`。

1. **背景录下来**（`Backdrop.kt`）：页面内容在画的时候同时录进一个 `GraphicsLayer`。玻璃再把这层画一遍（画的是 RenderNode 引用，不是拷像素），所以列表一滚，玻璃后面同一帧就跟着变。
2. **一个 AGSL 着色器做完所有事**（`GlassShader.kt`）：圆角矩形的 SDF 算出每个像素离边多远；边缘按四分之一圆的斜面弯折采样点（折射）；红蓝两个通道弯得不一样多（色散）；再加饱和度、着色、沿边的高光、手指按下处的光、外面的阴影。模糊在它之前做（`RenderEffect` 链）。
3. **按下会鼓起来**：不是把控件放大（那样背景也跟着放大，对不上），而是在着色器里把轮廓长出去。
4. **Tab 栏的透镜**（`GlassTabBar.kt`）：选中的那块本身是一块玻璃，看的是 Tab 栏自己。按住它会变大、变清、放大下面的字，拖动时按速度拉长，松手弹到最近的一格。
   离开一格的时候它还黏在那儿：那一格上留下一个鼓包，中间牵出一条丝，越拉越细，到一格宽的地方断开。不是把两块画出来再模糊、再卡阈值，是把两个形状「离边多远」的距离取一个软的最小值——腰自己就鼓出来了，多算一次距离而已。
5. **设置 › 外观 › 玻璃实验室** 可以拖一块玻璃、调每个参数看效果。气泡、卡片、顶栏、Tab 栏、输入框和 Tab 透镜都能单独调、用到 App 里；
   透镜调的是它停着的样子，按住、拖动时按同样的比例跟着变（色散调成 0，按住也不出彩边）。
6. **换 Tab 横着滑**（`MainScreen.kt`）：页面在布局里待在原位，只把画出来的那层横着挪（页面自己一层 graphicsLayer，画一次整张挪）。
   按位置挪的话，页上每块玻璃压到屏幕边时都要重建效果，两页几十块每帧重建，就掉帧、闪；代价是滑的 0.3 秒里透过气泡看到的壁纸跟着页面走。
   每一页都挂在自己的 `key` 下：滑之前在屏幕上的那页，滑的时候、滑完以后都是同一页，不重建；
   要滑进来的那页先在屏幕外面建好、画两帧，再开始动。
   四页打开过就一直留着（没开过的在 App 起来后陆续在屏幕外建好），不在屏幕上的只量尺寸、不摆放，所以不画；
   页面靠 `LocalPageShown` 知道自己是不是正在显示，聊天页据此停语音、停「在打字」、不算「正看着」。

## 工具调用是怎么接的

`app/src/main/java/com/cleo/cleos/ai/`。一次回复是个循环：模型回文字、调用或两者都有 → 执行调用，结果送回去 → 模型接着说，直到它不再调用（最多 5 轮）。

- 每一步都当场存进数据库（说的话、调用、每个结果），所以停止、崩溃之后记录和实际做过的事对得上；「重新回答」从结果接着答，不会把同一条待办再加一遍。
- 历史里调用和结果必须成对：窗口从中间截断、停在工具执行中间，都会留下落单的一半，发出去之前配好对，落单的去掉（`Prompt.pairCalls`）。
- DeepSeek 在开启思考且使用工具时保留并回传所需的历史 `reasoning_content`，包括此前轮次；其他模型保留原来的轮次规则。
  `deepseek-flash` 关闭思考时明确发送关闭参数。普通 HTTP 400 / 404 / 422 不会被当成不支持工具；只有接口明确拒绝对应功能时才降级。
- 小秘密不靠「记得过滤」：给模型读日记的查询本身就带着 `secret = 0`，锁着的那篇连标题都不会进请求。
  别的 TA 的日记也一样：查询只认你的和这个 TA 自己写的（`companionId`），别人写的进不了请求。
- 流式的调用参数是一段段来的，各家拼法不同（有的不带 index、有的整段给、有的参数给成对象），`StreamParser` 都认。

几条踩过的坑写在代码注释里（为什么要 overscan、为什么采样点要夹在屏幕内、为什么背景副本只录不画、为什么二级页切换用淡入淡出不用滑动，以及底下 Tab 换页凭什么可以滑）。

## 构建

用 Android Studio 自带的 JDK（21）：

```
./gradlew assembleRelease
```

签名读根目录的 `keystore.properties`（已在 `.gitignore` 里，别提交）：

```
storeFile=/path/to/upload-keystore.jks
storePassword=...
keyAlias=...
keyPassword=...
```

有这个文件时 debug 和 release **用同一把钥匙签**：换钥匙装不上，唯一的办法是卸载，而卸载会清掉 App 里的全部数据。

国内网络拉 Google Maven（dl.google.com）要代理，可以在命令行加
`-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7890`。

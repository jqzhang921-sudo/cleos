- 文字、已有图片、图片署名与授权、摘要笔记、看图感想和笔记中的问题沿用原资料。没有图片仍可阅读；不宣称真实旅行、自拍或已读完整网页。浏览与整理不调用模型，不改阅读进度和次数。

- 移除专题只删除分组和顺序，原见闻、配图、进度和笔记保留。原见闻删除后关联级联移除，空专题仍保留标题并提示重新整理，不把缺失资料显示为已读。
- 数据库关联同时校验专题与文章的 TA 归属。私人书房、私人相册、自由写作与其他 TA 不进入候选或专题；换 TA 清理上一位的局部编辑与阅读选择。
- 完整备份包括专题与有序关联，旧格式 25 未带专题时按空列表恢复。导入校验重复、范围、归属和公开资料关联，失败不替换现有资料。API Key 和独立许可遵循原备份规则。

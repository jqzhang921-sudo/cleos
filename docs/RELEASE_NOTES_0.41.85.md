# Cleos 0.41.85

- 群聊顶栏新增「群内小本本」，沿用玻璃卡片。可以手动记下一条、搜索、修改和确认删除；长按已发送的群消息，选择「记到群里」即可整理保存，也保留「选择文字」入口。
- 从消息整理的记录保留原消息引用，能查看原文。同一条消息再次记下时打开已有记录，避免重复；修改记录不改动原聊天，删除记录也不删除原消息。
- 每群的小本本独立，当前成员及之后加入的成员可以使用本群共同记录；不会自动读入或写入私人记忆、私聊或日记。每次回复按当前话题的本地关键词匹配和最近更新时间选取记录，最多 12 条、上下文最多 6,000 字符，单条保留完整内容和来源。暂不做语义检索或模型自动写入。
- 每群最多 100 条，每条标题 60 字、正文 2,000 字；回复中可查看，待本轮结束或停止后再编辑、删除。数据恢复期间拒绝旧界面的保存操作。
- 数据库 33 → 34 新建独立群内记录表，不重写旧聊天。备份格式 4 包含群内记录和来源，继续读取旧格式；旧版需先更新才能恢复新版备份。恢复前校验来源属于同群，拒绝错误引用、重复来源或超出数量限制的记录。

674 项单元测试全部通过，正式包构建、发布必需的 lint 与原签名检查通过。实际生成的数据库迁移及 DAO 语句已在合成 SQLite 验证；现有 Android 模拟器从 0.35.2 覆盖升级后，完成小本本保存、修改、搜索、原文引用、重复来源、删除确认和进程重启后的数据保留检查，保留旧模拟器数据。取消删除或修改后保留搜索条件，测试群已清理、模拟器已关闭。

真实手机新地址的无线调试连接仍显示离线，本版尚未装入真实手机；真实模型回复读取小本本及手机完整备份恢复仍待实测。群内工具、图片、语音、自主互聊及全局长期记忆升级仍在后续计划中。

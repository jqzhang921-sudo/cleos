# 0.41.67：支持 Word 记忆导入

版本：0.41.67（144）。检查日期：2026-10-09。

## 问题与改动

之前的文件选择器允许选任意文件，但解析入口只识别 PNG 角色卡，其余文件直接作为 UTF-8 文本读取。DOCX 是压缩包，因此没有被正确解析。

- 「记忆」和「设置 → 数据」的导入入口现在支持未加密的 `.docx`，不需要转换成 TXT 或 JSON。
- 在本机提取正文中的段落、列表文字、表格单元格、超链接显示文字；保留中文、表情、换行及文字顺序。仍按现有记忆规则处理，导入当前 TA；同名合并、一类最多 10 件及溢出放进「设定」的行为不变。
- Word 内容不会创建角色卡或新的 TA。图片、绘图/文本框、页眉页脚、批注及排版不导入，不做 OCR，也不访问文档中的外部链接。
- 普通 ZIP、空文档、损坏文件、旧版 `.doc` 与加密文档给出明确提示；后两种请先另存为未加密的 `.docx`。
- 保留原有 32 MB 文件限制，另对解压体积、正文 XML、文字长度与嵌套深度设置上限，并拒绝 DTD 和外部实体。
- 不新增库依赖，不改变数据库结构、模型配置或聊天记录。

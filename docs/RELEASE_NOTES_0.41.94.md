# Cleos 0.41.94

- 群聊新增用户语音消息：按住话筒录音，松开先转文字，上滑取消。沿用「设置 › 发语音」的转写服务，最长一分钟。
- 转写完成后可播放原录音、修改文字或移除，点击发送后才让成员按原点名 / 轮转规则接话。成员收到转写文字，不将文字理解伪装成听到声音。
- 转写失败保留草稿并支持重试；移除、切换群及停止应用后，迟到结果不会写入新的草稿。语音草稿与已发送录音独立归属本群，随群删除和备份管理。
- 语音气泡支持播放与展开文字，草稿沿用玻璃实验室卡片材质。备份缺失录音时保留已有转写；已编辑的草稿文字可作为普通文字草稿继续发送。
- 修复流式请求取消时的竞争：回复总时限关闭连接产生的 Socket closed 不再替代取消原因，避免超时偶尔被显示为普通网络错误。

数据库升级到 38，37→38 仅新增可空的群语音草稿、消息音频字段。备份格式升级到 8，可读取旧格式；恢复新备份需要更新 App。

768 项单元测试、正式签名构建和发布必需 lint 通过；实际生成的迁移与 DAO 条件使用合成 SQLite 验证。模拟器验证录音、上滑取消、转写失败重试、移除时取消、编辑后发送、两位成员轮转、原录音播放和跨群草稿隔离。

接口测试使用临时调试配置与本地合成响应，验证了实际客户端请求和状态处理，不代表真实语音识别精度。最终正式包保留原网络策略，并完成覆盖升级、记录保留、播放及合成备份导出 / 恢复；恢复后两群的录音字节和已编辑转写均保留，未自动发起转写或聊天。真实手机端口已失效，本版手机安装与真实录音 / 转写服务尚待实测；完整个人备份恢复、其他机型和长期使用仍待验收。

本轮只接入用户语音消息。TA 语音回复、多人实时通话、自主互聊及电脑版继续后续计划。

# Cleos 0.41.103 · 模型与 MCP 的 HTTP 兼容

- 聊天模型、通话模型和 MCP 支持 HTTP。每个新主机和端口默认不允许明文连接，开启时显示玻璃风险弹窗，明确确认后才生效。取消不授权，也不发送测试请求。
- 同一主机和端口上的聊天 / 通话模型共用授权，MCP 按服务独立授权；改变主机或端口不会沿用其他地址的许可。授权涵盖该主机端口的所有路径，保存于本机加密存储，不导出到 Cleos 备份。补齐 Android 10/11 对密钥与授权存储的系统备份排除规则，Android 12+ 保持已有排除。
- 每个模型请求（含测试、模型列表、地址 / 参数兼容重试）和 MCP RPC 请求发送前检查授权。关闭后拦住新发起的请求，已经在进行的请求不会自动中止。删除 MCP 服务同时移除该服务的 HTTP 授权。
- 共用网络客户端在请求开始及重定向后的实际发送前检查：普通联网请求继续只允许 HTTPS；模型 / MCP 不允许跨主机、端口或协议跳转携带凭据。支持同一 HTTP 来源的相对路径跳转；跨来源跳转需要核实后手动填写最终地址。没有放宽 HTTPS 证书校验。
- HTTP 仍然不加密。聊天 / 记忆 / 图片 / Key，以及 MCP Token / 工具参数 / 结果均可能被截取或篡改。提示不替代传输保护，建议可信自建或局域网使用，公网优先 HTTPS。

数据库 40、备份格式 11 不变。没有为转写、声音生成、图库或资讯开放 HTTP。本版是现有群聊改动之后的兼容收尾，TA 看世界仍为后续独立阶段。

验证：917 项测试、正式构建和发布必需 lint 通过。新增 11 项许可与真实本机 HTTP 测试覆盖取消前零请求、按服务隔离、撤销、模型流 / 列表 / 测试、MCP 初始化 / 列工具 / 调用、同源跳转和跨来源零目标连接。OPPO 最终正式包同签名覆盖安装 .103 / 180，实测模型 / MCP 明文连接与提示开关，关闭后不再发送新请求。使用合成服务和假 Key，没有改动原聊天或保存测试模型配置；临时 MCP 服务、测试授权与调试隧道已清理。其他机型和真实自建服务尚未据此标记通过。

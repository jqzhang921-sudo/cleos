# Cleos 0.41.132 · 书房的第一次阅读

- 书房可粘贴文章标题、来源和纯文字正文，按 TA 独立保存；同一 TA 的相同正文去重，最多 50 篇、每篇 10 万个字符。来源链接只作记录，不自动抓取网页。
- 「让 TA 读一会」先由 TA 挑选未读文章，再阅读至多 3000 个字符；可以暂时不读，也可以读后不留笔记、不发消息。每天最多 5 次手动机会，没有开启新的后台自动任务。
- 阅读位置由实际提供的原文范围确定；只有收到完整、有效的确认才保存。可停止阅读，网络失败、错误摘录或进程中断不会提前推进。
- 随手本保存 TA 主动写下的可读想法、问题和逐字摘录；可搜索、删除及回到对应原文片段。模型的普通输出、思考流和未完成的工具参数不保存为笔记。
- 首页显示真实的最近阅读和未完问题。文章和笔记按 TA 隔离；删除文章会在确认后删除关联笔记，删除 TA 会清理其世界资料。
- 数据库以非破坏迁移升级至 45，手机备份格式升级至 16，包含文章、阅读位置和笔记；仍读取旧版备份。执行中的阅读不会从备份恢复或自动重放。电脑版 0.13 暂不支持格式 16，需要以后更新再导入，避免丢掉世界资料。
- 重复导出到同一文件时明确截断旧内容，避免较短的新备份尾部残留旧 ZIP 目录、导致校验失败。
- 尚未开放自动后台探索、网页抓取、通用 PDF / EPUB、新闻、照片读取或聊天中的笔记检索；旧入口的照片与日历权限没有因此扩大。

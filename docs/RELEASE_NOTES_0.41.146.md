# 0.41.146 图文见闻与单次看图

## 行为

- 窗外的摘要可打开独立的图文见闻页，依次展示实际保存的公开配图、来源文字和 TA 已保存的感想。来源说明与 TA 的笔记分开；不冒充旅游亲历、全文阅读或 TA 实拍。
- 用户可手动让这位 TA 看这一张配图。请求发送真实图像数据、配图说明和角色设定，需配置支持图像的模型。结构修复仍携带同一张图，图像拒绝不退化为只读文字。
- 看图确认单独保存，允许看过而不写笔记；暂停不会标为看过。看图与阅读共用每天五次机会，失败和停止退回，摘要阅读位置不变。
- 随手本可按内容、问题和来源标题翻找阅读笔记与看图记录，再返回原文或图文见闻。删除一条记录保留配图和摘要；移除图片会移除它的看图记录，文字阅读笔记保留。
- 图片只有小幅滚动层次，关闭立体滚动、系统关闭动画或切离页面时禁用；没有无限动画，滚动不联网、不调用模型。
- 世界页的目的地、所选 TA 和动效选择由可恢复的导航状态持有；系统字号重建页面时保留当前见闻，等待 TA 资料加载时不重置目的地。刚开始就取消也释放阅读占用。

## 数据与边界

- 数据库 54 → 55：新增 world_picture_looks；本地运行状态新增 pictureArticleId，避免把另一张图片的结果显示到当前来源。既有文章、图片和文字笔记不改写。
- 备份 22 → 23：携带独立看图记录，恢复前检查图片归属、像素哈希、记录编号 / runId 和共享随手本上限。旧备份无看图记录时为空；后台授权仍不从备份恢复。
- 取消、换模型 / 角色 / 密钥、图片移除和恢复前排空均阻止旧结果晚写入。没有新增后台图片权限，也没有自动读取相册。
- App 能保证发送了图像数据并收到指定结果；无法独立证明上游模型内部是否实际关注或理解图像。

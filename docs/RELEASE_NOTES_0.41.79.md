# Cleos 0.41.79

- 「主动逛朋友圈」增加每位 TA 独立的「动态偶尔配图」开关。开启后，TA 在原来的逛逛机会里自行决定纯文字、带一张图库照片或保持安静；手动「让 TA 逛逛」也使用这个开关。
- 复用「能做的事 → 找照片」中选择的图库。只有 TA 提出配图关键词时才查询图库，并额外请求一次模型，从最多 6 个真实候选中挑图或改为纯文字。挑图依据照片描述，未让模型观看候选画面。
- 配图随动态保存，显示作者、来源、许可及预览说明，复用现有玻璃样式、备份和删除流程。图库图不冒充 TA 的拍摄或新闻现场照片。
- 设置改变、开始聊天或跨入免打扰时间会停止后台发布；配图下载或保存失败时不留下空动态，重复动态与未提交图片会清理。已提交动态的图片不会因随后取消而被误删。
- 保留现有逛逛频率、夜间免打扰和每位 TA 每天最多自动发 1 条的限制。新配图开关默认关闭，随备份保留，删除 TA 时一并清理。

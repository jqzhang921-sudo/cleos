## 使用路径

进入「世界 → 相册」，用系统照片选择器一次选一张照片。只复制所选照片到这位 TA 的独立相册，缩放至最长边 960 像素并重新编码，去掉原图定位及 EXIF。相同原照片选给不同 TA，也分别保存，不自动共享。

添加和改说明只保存在本机。点「让 TA 看」后有单张发送确认，向 TA 当前模型发送实际图片、这一张的说明与角色设定；接口须支持图片。看过、看过但没写感想、暂时不看各自区分。感想和疑问只保存在这位 TA 的相册，不进入公开主题、窗外、朋友圈或其他 TA 的上下文。

相册看图与阅读共用每天 5 次机会；失败和停止退回。照片或说明变化会停止对应请求；删除移除该照片及派生记录，保留手机原照片。恢复资料撤销旧照片选择和待确认发送的资格。

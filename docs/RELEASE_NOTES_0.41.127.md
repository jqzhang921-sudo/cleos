# 0.41.127 · 迁移到电脑（开发验收版）

数据与备份中新增「迁移到电脑」，配合 Cleos Desktop 0.3.0-preview.1 使用。同一 Wi-Fi 下扫描电脑临时二维码，核对设备和数字，手机确认整份备份范围，电脑同意后才准备并传输；不含 API Key。也可以复制/粘贴配对码。

使用临时证书指纹固定的 TLS 1.3 连接，二维码限时且只允许一次认证。传输完仍需在电脑预览并确认导入。手机资料和原电脑资料保留；不是同步。扫码只在用户点击后申请相机，没相机也能使用其他功能。

当前只支持完整备份，包含日记和小秘密；请在确认页核对。保持传输页面在前台，切后台或离开会取消；断开需重新扫码。手机原始 ZIP 导出/恢复入口保留。本轮没有改动群聊和模型请求逻辑。

这是配套开发验收包，尚不能把本机合成传输测试称为真实手机跨设备验收。

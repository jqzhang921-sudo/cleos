# 0.41.143 · 让兴趣自己往前走一点

「世界 → 窗外」和「继续查阅」新增「让 TA 沿着兴趣查阅」。这是每位 TA 在本机的独立开关，默认关闭，不改变已有书房或订阅源的自主权限。开启后约 15 分钟给首次机会，之后约每 4 小时一次，由系统及网络安排，不连续补跑错过的机会。

TA 可根据角色设定与近期两条公开笔记选择一个公开主题，也可以不查。选出的检索词将发到中文维基百科，最多取回三条真实导言摘要，再选择是否阅读、留笔记。检索词、原始来源与获取时间保留；获取摘要与确认读过分别记录，不表示已读全文、看图、亲历或解决了问题。相同检索词经过字符规范化、大小写和空白合并后，24 小时内不重复搜索。

选题、选择摘要与阅读通常最多三轮模型请求，每轮格式纠正最多一次，合起来只占用共用每日五次的一次机会。选择不查或不读正常计次；失败、无可读结果或停止退回次数。只接受完整结构化结果，普通文字和内部思考不会写入随手本，摘录仍须与实际片段逐字匹配；没有聊天或分享工具。

关闭开关会取消本轮自主选题、查询及阅读，以及后续机会；手动查阅、书房和订阅浏览分别保留。模型 / 角色改变、任务停止、备份恢复和删除角色会阻止过期结果继续阅读或落库。缺配置、额度已满、忙于聊天 / 通话、另有获取任务或窗外已满时提前跳过网络。

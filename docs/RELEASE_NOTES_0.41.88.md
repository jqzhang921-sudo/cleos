# Cleos 0.41.88

- 群聊可以发送公开图库图片卡片了。TA 搜索后可自行选择真实候选，图片显示在发图成员名下，可点击看大图。
- 保留图片标题、作者、来源和许可，采用玻璃实验室卡片材质。没有作者信息时如实提示。
- 每位 TA 每次回复最多 3 张；失败不假报发送成功，停止取消后续操作，重试只处理这位成员的旧尝试。
- 图片随群聊保存和备份。停止后已经保存的图片仍保留，后续文字模型读取来源说明，不自动提交图片像素。
- 修复诊断记录原子写入被短暂拒绝时偶发丢行，采用有次数上限的重试。

数据库 35→36；备份格式 6，兼容旧备份，旧 App 需更新后恢复新备份。720 项测试、正式构建与发布必需 lint 通过。同签名覆盖安装，实机已验证搜图、发图、大图查看及重启保留。

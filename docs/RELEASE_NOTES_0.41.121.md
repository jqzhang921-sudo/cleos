# Cleos 0.41.121

- 在「说话方式 → 想找你聊」中增加每位 TA 独立的「TA 主动来电」，默认关闭。开启后 TA 可在原有自主联系机会里选择邀请语音通话，沿用免打扰时间。
- 新增玻璃来电卡和带接听 / 拒绝操作的来电通知。只在接听并获得麦克风权限后开始通话，TA 先开口；拒绝、未接、忙线和已接通的结果留在聊天通话记录中。
- 每位 TA 最近 24 小时最多主动来电 2 次，两次至少间隔 6 小时；邀请 45 秒后过期。重复点击、过期通知或恢复备份不会自动接通旧来电。

数据库升级到 41，备份格式升级到 13。旧备份仍可读取；待接邀请和来电频率账本不从备份恢复，历史中未完成的来电按未接 / 中断结束。

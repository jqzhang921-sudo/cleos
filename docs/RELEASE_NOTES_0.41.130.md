# Cleos 0.41.130 · 世界的空间滚动

- 世界首页沿用 App 的壁纸和液态玻璃，增加独立的 TA 选择、最近在读的空状态、四个空间卡组与未完问题的位置。
- 左右滑动时，空间卡片以透视、缩放和错层衔接，停下后居中；也能点击文字页签定位，进入书房、窗外、随手本和共享相册的筹备页。
- 可关闭立体动效；系统关闭动画时自动退回平面显示。没有自动轮播或持续旋转。
- 返回首页保留滚动与所选卡片。世界里的 TA 选择独立于聊天，隐藏页面不会拦截聊天的返回操作。
- 仍未接入真实阅读、笔记、后台探索或照片权限，不展示虚构的阅读记录。数据库仍为 44，备份仍为 15，电脑版没有变化。
- 本版包含 0.41.129 的「记录」合并入口及日记 / 待办切换。

# 气泡方案与气泡包 v1

气泡实验室的「保存与分享」保存当前双方的气泡主题、当前主题背景、我的玻璃底色、留白和所有装饰。使用方案时，TA 的主题应用到当前角色；留白和装饰沿用应用的全局设置。壁纸、聊天、账号和 API 配置不进入气泡包。

`.cleobubble` 为 ZIP，包含 `theme.json` 和引用到的 `images/<文件名>`。清单字段为 `format: "cleos-bubble"`、`version: 1`、`preset`。preset 对应 BubblePreset 数据结构；图像引用包括原有小脸、星点及独立组件。

导入先检查结构、清单版本、引用完整性和图片尺寸，再复制图片并分配新的内部文件名与方案 ID。导入只添加方案，不立即应用。方案图片也进入普通完整备份。

限制：最多 50 套本地方案；清单最大 256 KiB，单张文件最大 8 MiB，总解压数据最大 32 MiB；导入图片最长边不超过 2048 像素。未知路径、目录、重复 ZIP 条目、不匹配的图片引用以及未知版本会拒绝。

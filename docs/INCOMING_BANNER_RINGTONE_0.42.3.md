# Cleos 0.42.3 · 来电横幅与铃声入口

App 内来电改为顶部玻璃横幅：头像、名字、来电状态，右侧红色拒绝与绿色接听按钮。从上方轻滑入，结束时收起；系统关闭动画时直接显示。长名字省略，大字号下操作按钮换行，点击区域至少 48dp。仅用一层玻璃承载，两个操作按钮采用轻染色。

锁屏来电 Activity 复用同款卡片，保留解锁与麦克风许可流程，不展示私密来电原因。App 内横幅也不再直接展示模型提供的邀请原因。系统通知横幅仍由 Android / 手机厂商绘制。

设置 → 说话方式 → 主动来电中，新增独立“来电铃声 / 选择铃声”入口，显示当前通道的铃声或静音状态。进入系统来电通知设置可选择声音及振动；返回后刷新名称。入口不依赖“持续横幅与锁屏来电页”开启。

原有 `incoming_calls` 通知通道已承担前后台来电铃声，本次沿用该通道，不重复创建音频播放器，也不重置用户已有的声音设置。Android 通道的声音由用户控制，参见 [NotificationChannel](https://developer.android.com/reference/android/app/NotificationChannel)。接听操作在询问麦克风许可前取消来电通知；拒绝、失效等仍沿用原来的通知取消路径。

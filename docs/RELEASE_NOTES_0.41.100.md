# Cleos 0.41.100 · 通话话筒与声音占用处理

- 话筒读取返回错误或抛出异常时，转为受控失败并结束通话，清空收音状态，不让界面一直停在正在听，也不让读取线程的异常直接导致进程退出。私聊和群通话共用处理。
- 静音、取消静音、声音焦点改变和重新开始收听都会切换录音片段的有效范围。切换时正在读取的一帧、暂停前未完成的一段话和已经排队但尚未使用的识别事件，不会跨入恢复后的收听；重新说即可。
- 结束通话时先关闭话筒以唤醒阻塞读取，再限时等待线程退出。话筒只关闭一次；即使异常驱动迟到返回，也不再检测或发布结果。私聊清理放在 IO 线程，并保证记录结束失败时仍关闭前台服务。
- 系统拒绝声音焦点时提示并退出，不打开话筒。临时失去焦点或收到降低音量请求时暂停收听、打断本轮并停止播放；恢复后重新听用户说，丢失期间不接着播放旧句子。永久失去焦点时结束通话。结束后的迟到焦点回调不再更新旧通话。
- 私聊等待接听的铃声及两种通话的语音播放都检查声音占用状态，避免只清掉当前声音后继续写入后续音频。

878 项测试（新增 17 项）、正式构建与发布必需 lint 通过。本轮使用合成录音帧、可控阻塞 / 异常话筒和焦点回调完成离线验证，没有连接手机、录音或请求真实语音服务。真实声音、原生音频焦点、来电、耳机、扬声器、切后台与打断延迟仍待实机验收。数据库仍为 40，备份格式仍为 11；仍为用户加两位 TA 轮流通话试用。

Android 音频焦点行为依据：[官方文档](https://developer.android.com/media/optimize/audio-focus)。本地模拟的控制逻辑通过，不等同于特定机型上的系统行为已经通过。

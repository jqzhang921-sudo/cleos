# 0.41.68：拦截普通图片误导入

版本：0.41.68（145）。检查日期：2026-10-09。

## 修复

此前导入入口在没有找到 PNG 角色卡资料时，会把普通图片继续当成 UTF-8 文本读取，存在保存乱码记忆的风险。

- 普通截图、照片会在写入数据前被拦截，提示先提取图片文字，再粘贴到设定或另存为 TXT / DOCX。
- 同时检查文件内容与文件提供方的图片类型标记，覆盖 JPEG、普通 PNG、GIF、WebP、BMP、TIFF、HEIF/HEIC、AVIF；图片类型标记也可拦截 SVG 等其他图像。
- 内嵌角色资料的 PNG 角色卡仍可导入。DOCX、JSON、文本等原有导入逻辑保留；内容明确是 DOCX 的文件仍可在提供方类型标记错误时读取。
- 记忆、设定和设置中的导入说明增加普通截图提示。
- 当前不提供 OCR 自动识别，不上传图片给模型，也不清理之前已经存在的条目。不涉及数据库迁移。

本版同时包含 [0.41.67 的 Word 记忆导入](RELEASE_NOTES_0.41.67.md)。

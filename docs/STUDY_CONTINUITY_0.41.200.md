# 书架记忆衔接 · 0.41.200

这轮打通书架与私聊/电话/主动消息之间的记录衔接。手动 PDF 分卷归组仍单独待做；本轮不改布局或自动合并规则。

- 开启现有「回想世界」后，每轮私聊、电话、主动消息在当前用户回合附加少量当前 TA 的实时书架近况和想读历史。关闭后不加入新近况；此前进入对话的材料仍属历史消息。群聊不加入私人书架。缓存用的系统前缀不加入动态书架。
- recall_world 同时返回 study.books / study.wishes，包括想读理由、用户确认的关联、已上架未读/部分阅读/读完导入文字。没有笔记仍能通过保存的进度回想。相同标题仅列为候选，不自动认定为同一本；已删除的关联来源标为缺失。
- 选书带入相关想读历史及读书记忆；正式续读带入同一本已读分卷的少量既往笔记、疑问与已确认读过的末尾最多 600 UTF-16 单位片段。当前新段仍独立确认，摘录必须来自新段。
- 读书偏好沿用「记忆」开关，只取当前 TA 的最多 4 条相关名称/摘要，不携带记忆详情和聊天全文；开启阅读时的界面说明已更新。
- 既往笔记限当前书及其已识别分卷，验证所有权、边界及实际已读范围。结果保存前重新核对阅读上下文；删除或改动参与的记录会令旧结果停止保存。
- 使用现有源记录实时投影，未增加数据库表或持久化摘要。数据库仍 66，备份格式仍 29；源删除或归属改变后，下次读取不会从额外缓存复活旧书。现有工具权限、防伪调用、群聊范围和私人相册边界保持。

验证与包身份以会话 outputs/Cleos-study-continuity 的 JVM-RESULTS、NATIVE-CHECKS、PRESERVATION-RESULTS、LOCAL-ACCEPTANCE 和 PHONE-INSTALL-RESULTS 为准。原生请求均为本机合成接口，不调用真实模型。

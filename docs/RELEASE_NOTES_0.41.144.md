# 0.41.144 · 书架整理与自己的书签

书房新增「我的书签」，与 TA 的阅读位置分开。打开原文后可在段落开头留书签、填写可选名称，之后搜索、回到该段或确认移除。同一位置再次保存会更新名称，不重复新增。书签名称仅保存在本地，不发送给模型，不推进 TA 的阅读进度或消耗阅读机会。

读物可整理为书籍、杂志或文章；杂志可填写刊名与期号，按刊名和期号排列。既有读物保留为未分类，用户可以自行整理。这是本地分类，不会联网订阅、下载或核实刊物。分类、期号和书签均不改写导入原文、版本指纹、摘录坐标或阅读位置。

每位 TA 的书签与整理信息独立。删除读物会连带移除它的书签和分类；删除 TA 不影响其他 TA。数据库 52 → 53 只新增两张表；手机备份升级至 21，包含书签和整理信息。旧备份可读取，三类本机自主授权仍不导出或继承。电脑版 0.13 暂不支持新备份格式。

验证：1199 项单元测试、13 项原生场景、6 项界面检查通过，正式签名构建及 lint 通过（0 错误、48 项既有警告、11 项提示）。正式包覆盖升级从数据库 52 到 53，原有 24 条文章、2 条想读和 1 条执行状态逐字段不变，新表为空；该迁移样本没有笔记，笔记精确保留另由备份及原生检查覆盖。大字体、跨 TA、取消删除、同位置改名、旧界面写入拒绝、备份校验和删除级联已检查。证据位于工作区 outputs/Cleos-0.41.144-shelf-tools/。

手机当前离线，尚未安装此版。验收仅使用合成资料，无真实模型请求、麦克风或用户相册访问。书签片段仍可能包含 EPUB 原文分段标记，后续显示优化不改变其原始位置。图文窗外、共享相册、在线正文书源和最后的视觉统一仍在持续目标中。

# Cleos 0.41.111

- 后台主动聊天、记下的事、早晚招呼和逛朋友圈，遇到 DNS/连接中断等临时网络错误时，在没有收到模型输出的前提下等待 2 秒、8 秒重试；每次主动机会共用两次额外重试额度。
- 收到文字、思考或工具调用后不自动重发这一请求；HTTP 拒绝、证书和 HTTP 授权错误不重试。不会重新执行已经运行的工具或重放整次主动机会。
- 后台调度被取消时，一并停止还在等待的主动请求并等待清理，随后仍可处理期间收到的用户消息；执行记录收尾不受协程取消打断。
- 新产生的未收尾记录在下次启动时尽可能关联开始后 15 分钟内的系统退出记录，区分安装更新、内存回收、崩溃和未提供具体原因的系统结束。这只是时间关联，不宣称已证明因果；历史不可用时明确说明无法对应，不采集系统堆栈或聊天正文。
- 新增短重试只针对当前模型请求，记录恢复本身不重放 HTTP 请求或工具。仍在有效期内的到期事项和早晚招呼，继续按原有调度与重试窗口另行尝试。旧记录保持原样；本次没有更改后台权限、省电设置、触发频率、每日限额、数据库版本或备份格式。

系统强制停止、后台冻结、长时间断网或无效域名仍可能造成中断/失败，短暂重试不能保证全天后台执行。

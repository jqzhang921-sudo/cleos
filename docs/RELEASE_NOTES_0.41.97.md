# Cleos 0.41.97

- 「设置 › TA 的声音」上方新增当前 TA 的音色卡片，沿用玻璃实验室材质。可跟随共用音色，或单独选择、输入音色 ID；点击「保存音色」才生效。试听、选择列表和未保存就返回不会改变已保存的专属音色。
- 每位 TA 的已保存音色用于私聊语音、群聊短语音、朗读和下一次电话。进行中的电话保持本次选定的声音，历史音频保持原样。声音平台、模型、接口和 Key 仍共用，没有增加每位 TA 独立平台或 Key。
- 音色按当前平台分别保存，MiniMax 国内版与国际版分开；「其他接口」另外区分地址和模型。切换后只使用对应音色，没有对应选择时跟随共用默认。也可保存「跟随共用音色」恢复默认。
- 保存针对实际 TA 编号与创建身份，配置已变化时提示重新打开，避免旧页面覆盖新数据。群聊合成途中更换该成员音色时，不再发布过时的合成结果；其他成员的音色和角色不受影响。
- 旧 TA 和新建 TA 默认跟随共用音色。数据库 39→40 增加默认空配置；备份格式升级为 11，保存各 TA 的音色选择，继续读取旧备份，新备份需更新 App 后恢复。备份不增加 API Key；格式错误的音色配置在恢复前被拒绝。

823 项单元测试、正式构建和发布必需 lint 通过。实际生成的数据库迁移及更新 SQL 通过内存数据库验证；正式包已同签名覆盖安装 OPPO，版本为 0.41.97 / 174，首次安装时间保持不变，未卸载或清除数据。

本轮未调用真实 TTS 平台或拨打电话，也未完成格式 11 的原生端到端备份恢复，不能将参数、序列化与迁移检查等同于完整声音效果验收。启动临时模拟器的命令被自动审批拦截（仅返回 `blocked by policy`），未重试或绕过。真实声音服务、转写质量、自然接话、其他机型和长期使用仍待验收；多人实时通话和后台自主互聊继续单独规划。

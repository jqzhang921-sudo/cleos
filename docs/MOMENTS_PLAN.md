# 朋友圈后续计划

2026-10-08，根据前面的讨论整理；按阶段实现和手机验证。

## 已确定的方向

- 这是用户自己的动态页，所有 TA 共用。朋友圈承载日常、照片和碎碎念；话题承载资讯与观点。
- 封面顶满，下面使用玻璃实验室的卡片磨砂材质。点封面展开后更换，不在主页面堆放设置项。
- 三点菜单下拉展开，保留玻璃材质和弹性动画。
- 转发入口统一为「转发到聊天」，由用户选择 TA，先生成聊天卡片，可附上一句话再发送。
- TA 发帖或回复时明确自己与其他人的作者身份，避免把自己的帖子当作别人发的。

## 当前完成

- 文字动态、点赞、评论、删除，以及手动让 TA 分享日常或资讯。
- 朋友圈和话题切换、共享主页封面和简介、按当前 TA 筛选。
- 转发对象选择、聊天玻璃卡片、完整内容快照与独立聊天草稿。
- 0.41.61：一次最多 9 张照片，支持纯照片或图文发布、多图网格和大图预览。
- 照片随动态备份，转发时建立独立副本；删除原帖不会破坏已转发的照片。
- 0.41.62：评论支持回复具体的人；菜单可手动邀请一位 TA 阅读正文或朋友评论，由模型选择点赞、评论或只阅读。同一段内容防止重复邀请，作者不回应自己的正文或评论。
- 0.41.63：每位 TA 可独立开启后台主动逛朋友圈，默认关闭；可另选自动发动态与资讯。提供频率、夜间免打扰、每日考虑次数和每天一条自动发帖上限；聊天或输入时取消当前自动阅读。

## 后续顺序

1. 收集图文版的实际使用反馈，完善发布、图片浏览和评论体验。
2. 收集手动邀请互动的反馈，完善评论展开、回复关系与 TA 表达；检查是否需要更灵活的阅读节奏。
3. 后台唤醒、主动逛朋友圈及发帖已接入（0.41.63）；接下来收集开启后的使用反馈，完善阅读节奏及回复展示。
4. 朋友圈体验稳定后，再推进共同目标存钱罐与月度小票。详细计划另存，当前不实现。

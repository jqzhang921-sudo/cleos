# 「窗外」规范融合记录

日期：2026-10-30。依据用户提供的《Cleos ·「窗外」产品与卡片文案规范 V1.0》，对照当前 .167 源代码、TA_WORLD_GOAL.md 和验收记录整理。

状态：本轮是设计评审与后续方案，未修改运行代码、数据结构、权限、模型提示词或安装包。原规范第 17 节作为待评估的实现建议，不直接视为本轮开始重构的指令。

## 1. 保留的核心方向

窗外呈现这位 TA 在授权范围内接触公开世界的过程：带回的资料、实际看过的片段、留下的感想，以及仍想追问的问题。用户可以旁观、参与和控制授权范围。

沿用安静、克制、自然、有好奇心的气质，允许内容少、允许不写笔记。继续保留用户壁纸、玻璃、图文交替、普通滚动和可关闭的小幅层次动效。

以 TA 自己的兴趣和探索为叙事中心。用户选择来源或优先主题，不等于把窗外改成“为用户挑选必读新闻”的推荐首页。当前没有完整兴趣画像，不能用文案假装已经准确推断用户喜好。

## 2. 原规范逐项处理

| 原章节 | 处理 | 与现有世界的融合方式 |
| --- | --- | --- |
| 01 产品定位 | 调整后采纳 | 保留自主探索、安静窗口、可控制。重点放在 TA 留意到什么和想继续了解什么，弱化面向用户的推荐排序。 |
| 02 文案气质 | 采纳并细化 | 少营销、不堆术语。保留 TA 的个性、喜好与主观表达；事实性活动状态须有记录，不凭空添加喝咖啡、旅行等现实经历。 |
| 03 页面结构 | 调整后采纳 | 将内容、实际活动、相关笔记分开；设置集中收拢。保留已有图文漫游、继续查阅和批量管理入口。 |
| 04 首页与数字 | 调整后采纳 | 默认展示近期见闻，日期分组；不强制只看今天。获取数、看过的摘要数、笔记数按各自记录计算；阅读机会不等于读过的条数。 |
| 05 卡片层级 | 采纳 | 来源与类型、原题、可折叠内容预览、真实阅读状态、少量操作。关注原因有可追溯依据才显示。 |
| 06 新闻卡 | 采纳 | 保留来源、原题和发布时间；获取时间另列。来源只提供摘要时，卡片始终标为订阅摘要。 |
| 07 书摘卡 | 保留原则，暂不混入窗外 | 原文、概括和感想分开。私人导入书籍继续属于书房，阅读笔记通过随手本关联，不并入公开窗外检索范围。 |
| 08 研究卡 | 分阶段采纳 | 真实获得的作者、年份、论文类型可展示；当前来源缺少的发表 / 预印本 / 同行评审信息不补猜。完整研究专用卡后置。 |
| 09 活动状态 | 调整后采纳 | 活动状态来自实际执行任务。只有真有整理步骤时才显示正在整理；完成当前摘要不写成读完整篇，字符进度不换算成虚构章节数。 |
| 10 笔记 | 采纳内容原则，分类后置 | 展示已保存的摘要笔记、看图感想和真实问题。当前没有独立“观察 / 关联 / 待查”分类字段，不能在渲染时猜分类或补写内容。 |
| 11 详情页 | 采纳 | 来源文字、TA 感想、问题及操作分区。继续探索明确意味着新请求；展开已有文字仅为本地展示。 |
| 12 设置 | 调整后采纳 | 集中展示已有来源和自主安排，保留浏览、续查、实际看图的独立许可。新的频率预设、来源管理和笔记策略需另做功能设计。 |
| 13 空状态 | 采纳并细化 | 区分没有资料、已获取但未看、看过但未留笔记，以及网络失败。有旧资料时显示旧资料，不用空状态覆盖。 |
| 14 反馈与删除 | 采纳 | 文案简短，删除确认说明实际依赖和范围。保留现有容量显示、来源筛选、全选 / 已读选择和批量移除。 |
| 15 空间边界 | 采纳并收紧 | 同一记录通过关联回看，不生成独立重复副本。复用显示组件不改变 TA 归属、私密性或聊天分享范围。 |
| 16 长度建议 | 采纳为视觉建议 | 预览可限行和展开；原题、英文标题、完整来源和时间不按中文建议长度硬裁数据。 |
| 17 实现要求 | 采纳兼容部分 | 复用现有能力、保护资料、统一可读性。没有后端能力或真实数据的按钮、分类和状态先不展示。 |
| 18 产品节奏 | 采纳 | 少量内容也成立，不要求每天产出，不为了页面热闹强迫 TA 留言或制造活动。 |

## 3. 建议的页面组织

保留世界的空间导航，窗外内部可整理为三个同级视图：

- **见闻**：默认显示近期获取的公开资料，标明 TA 是否看过摘要；可按日期 / 来源整理。图文漫游作为明显但轻量的入口，继续复用真实见闻。
- **足迹**：已保存的阅读与探索记录；当前确有任务时显示进度、更新时间和停止入口，失败显示真实重试入口。空闲时显示历史，不伪装成一直忙碌。
- **笔记**：仅展示当前 TA 与窗外资料关联的已保存笔记、看图感想和问题；回到统一随手本或原见闻。这里是视图，不是另一份笔记库。

窗外设置入口集中管理来源和已有自主选项，长说明折叠。停止本次任务、暂停后续自主机会应明确分开；移位置时不合并已有许可，也不替用户开启许可。

页首说明可用“看看 TA 最近留意了什么”。“读到了什么”适合已读视图，但不宜统称刚刷新而未读的资料。

本方案属于待实现布局，不意味着当前页面已经提供这三个视图。

## 4. 卡片与详情的统一规则

卡片采用“来源 / 类型 / 时间 → 原题 → 简短内容预览 → 实际阅读状态或已有感想 → 操作”的层级。内容预览首先复用已有来源摘要；没有摘要就不补一段虚构文字。页面打开或滚动不额外调用模型写一句话摘要、推荐原因或感想。

卡片可以使用已有且可用的公开配图；图片缺失时保留文字卡，不强制下载。保留作者、来源、许可与既有获取 / 看图授权。文字和图片错落陈列，细节页继续使用轻量滚动层次，避免巨幅标题和持续自动动画。

同一张卡最多保留一个主要动作和一两个次要动作；管理操作可以收进更多或管理模式。按实际能力选用“打开图文见闻”“查看摘要与来源”“查看笔记”。来源页由外部浏览器打开时使用“打开来源网页”，不承诺 App 已拿到全文。

窗外阅读产生的笔记已经保存并能在随手本显示时，使用“查看笔记 / 在随手本查看”，不再复制一条。尚无实际收藏或偏好数据时，不摆出无效的“精选”“不感兴趣”按钮。

详情页继续分开显示：来源提供的摘要、TA 的摘要笔记、曾留的看图感想，以及真实保存的问题。相关延伸有记录才展示；不要求每条资料都附带深刻观察。

## 5. 必须按真实含义调整的文案

| 场景 | 融合后的表达 / 规则 |
| --- | --- |
| 已获取而未阅读 | “刚带回的摘要，TA 还没看过。”仅在真实无已读进度时使用。 |
| 完成本地订阅摘要 | “TA 已看过这份摘要。”不能据此写“读完了这篇文章”。 |
| 看过但未保存感想 | “看过了，这次没有留下笔记。”前提是有实际完成记录。 |
| 部分阅读 | 显示真实位置 / 已读字符或比例；有可靠章节数据后再显示章节。 |
| 下次自主机会 | “下次机会：具体时间起，由系统安排。”不承诺准点开始。 |
| 无可靠选择原因 | 隐藏原因栏；现有检索词可以标为“查阅线索”，不冒充模型选择理由。 |
| 来源时间缺失 | “来源未提供发布时间”；获取于何时另行显示，不以获取时间冒充发表时间。 |
| 获取失败而有旧内容 | “这次没有取回新内容，已有见闻仍可查看。”不暗示整个网络都不可用。 |
| 获取成功但无新增 | “这次没有新的见闻。”不写成任务失败或 TA 不感兴趣。 |
| 批量移除 | 列出所选摘要及实际关联笔记 / 图片 / 看图记录数量；说明书房、未选见闻及私人相册的保留范围。 |

这些是条件化的文案规则；使用时还需逐个核对对应状态，不能只统一替换字符串。

## 6. 本阶段先搁置

1. 面向用户喜好的“猜你喜欢”、负反馈画像和强制每日精选。当前优先保留 TA 自主兴趣及允许不读、不写的节奏。
2. 无真实精选记录的精选数、无任务的正在整理、无章节索引的章数，以及“已找到资料”自动等同“已阅读”。
3. 将私人书摘、自由草稿和相册感想统一混进公开窗外；公开配图与用户指定私人照片仍分别管理。
4. 把所有自动行为合并成一个开关，或只改文案就宣称支持每天一次、每周几次和任意来源删除。
5. 没有可靠论文元信息时生成完整研究专用卡；没有来源数据时补写作者、评审状态或研究限制。
6. 把整个窗外改成不受限的自动联网浏览器。现有资料取回、网络可达性、模型读取和可选 Bing 网页入口的边界继续保留。

## 7. 后续实现顺序

本节与先前世界细化项已合并，统一阶段和优先级见 TA_WORLD_REFINEMENT_PLAN.md；本文件继续作为窗外具体设计与文案依据。

1. 先整理现有卡片层级、原题 / 日期 / 摘要标注与条件化状态文案，复用既有数据，不增加模型调用。
2. 再收拢长设置说明、整理见闻 / 足迹 / 笔记的视图与回看路径，保留批量管理和资料归属；验证页内返回、大字体和关闭动画。
3. 再接同一地方 / 主题的连续图文专题。先组织已有公开资料，后续新的取材能力独立设计，不能把图文陈列称为实际旅行或自动全网搜索。
4. 最后评估真正需要新增的兴趣、精选、笔记分类及来源能力，再决定数据迁移、备份和许可设计。

上述是安排建议，本轮没有开始实现、发布或安装。

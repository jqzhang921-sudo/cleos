# Cleos 0.41.124

- 支持每位 TA 独立的用户头像。主页点自己的头像，可「仅在这位 TA 这里更换」或「使用默认头像」；切换 TA 时，主页、单聊、表情回应和对应收藏会使用该 TA 的专属用户头像。
- 保留默认用户头像，群聊、群通话记录和朋友圈继续使用默认头像，未设置专属头像的 TA 也沿用默认；修改默认头像不覆盖已单独设置的头像。
- 选图 / 裁剪绑定开始选择时的 TA，避免切换、删除或更新资料后保存到其他人。更换、重置和删除时保留仍被其他头像或媒体引用的图片。
- 备份包含专属头像与图片；旧备份沿用原默认头像，缺失专属图片时回退到默认。

Room 数据库升级 41 → 42，备份格式升级 13 → 14；旧备份仍可读取。

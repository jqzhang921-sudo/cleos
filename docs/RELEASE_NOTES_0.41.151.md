# 0.41.151：翻译 TA 发来的消息

私聊与群聊里，长按 TA 已发完的文字消息 →「翻译」，默认翻成简体中文，可选繁体中文、英语、日语、韩语、法语、西班牙语、德语、俄语或葡萄牙语。原文保留，译文单独显示在下面，可收起、展开、复制及选择其他语言。第一版不提供用户消息、通话卡片、未完成 / 出错消息、纯表情包或超过 12000 字符消息的翻译。

确认翻译时，单独发送这条消息的正文给对应 TA 当前配置的主模型。群聊按原消息的发言 TA 解析接口与 Key，不使用当前选择的其他 TA；不附加人设、其他聊天、引用、图片、声音、工具或推理字段。会产生模型接口用量，确认界面有说明。翻译结果不写回聊天，不加入上下文、摘要或记忆。

同一消息、同一语言直接使用本地缓存；最多保留最近 500 份。修改正文后旧缓存不显示，删除消息时关联缓存一并删除。消息 / TA 配置 / 密钥变化、停止或恢复备份时，未完成请求不得保存旧结果。每条消息最多一项翻译任务，整个 App 最多并行两项，等待上限 90 秒；错误可手动重试。要求完整结构化结果，推理字段、工具调用、空结果、SKIP 或不完整 JSON 不作为译文显示。

数据库 58 → 59，仅新增独立的 message_translations 缓存表。备份格式维持 24，译文不随备份 / 扫码迁移；恢复资料时清除旧译文缓存，原始聊天保留。

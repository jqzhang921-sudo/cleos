# 0.41.134

修复书房失败后仍扣阅读次数、错误原因不明确的问题。

- 网络、接口错误、无效阅读确认和手动停止会退回本次占用的阅读机会，进度保持原处。进程中断后也只退回一次。
- 显示密钥验证、余额、限流、服务错误、超时、返回格式或摘录校验等原因，不显示接口的原始响应。
- 阅读请求明确要求返回阅读结果。接口拒绝工具参数或只给普通文字时，至多尝试一次完整 JSON 结果；仍校验选书归属、结果字段和原文摘录，不把普通文字或思考流保存成笔记。
- 对旧版处于失败、停止或中断状态的书架，升级时一次性重新计算当天次数，书籍、笔记和阅读位置保留。正常完成过且没有异常的次数不重置。

数据库升级至 46，仅增加书房错误分类并修正异常次数；备份维持 17，旧备份继续支持。后台自动阅读和在线书源不在本次范围内。

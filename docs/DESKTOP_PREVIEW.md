# Cleos Windows 预览版

当前版本：`0.13.0-preview.1`，扫码迁移配套手机版本仍为 `0.41.127`。这是独立的 Windows x64 客户端，使用 Kotlin/JVM 与 Compose Multiplatform；不依赖安卓运行环境。本轮改为 Enter 发送、Shift+Enter 换行，并新增点击录音、试听、显式转写、编辑确认后单聊/群聊发送。信件与收藏的只读浏览保留。聊天、日记、待办、信件、收藏、设置为平级主页面，左侧图标导航直接切换。查找当前对话和最近附件从聊天顶部「常用」按需打开，TA 资料点击头像/名称查看。保留 0.8.1 的 Windows 导入修复。扫码、手机 ZIP 导入和电脑备份位于「设置 → 数据与备份」；持续同步仍未接入。使用同一默认资料目录可继续打开旧预览版的资料；需先关闭正在使用该目录的旧程序。

## 启动与首次配置

解压整个便携包，打开其中的 `Cleos.exe`，保留旁边的 `app`、`runtime` 和 `licenses` 目录。包内带 Java 运行环境。

首次启动会建立一个空白 TA。点击「配置 TA 的模型」，或点击聊天顶部的头像/名称打开资料，再进入「角色与模型设置」，填写 TA 名字、角色设定、兼容 Chat Completions 的接口地址、模型名和 API Key，再保存。地址可填写服务商提供的 `/v1` 地址或完整 `/chat/completions` 地址，不会自动切换到另一个域名。

输入框使用 `Enter` 发送、`Shift + Enter` 换行（仍兼容 `Ctrl + Enter`）；回复时可停止，收到的部分内容保留。消息可以选中文字，或右键复制正文。思考默认折叠，不与正文混排。

左侧 `＋` 添加其他 TA。至少有两位 TA 后可「发起群聊」，选择 2–4 位。每位 TA 使用自己的角色和模型，顺序回复，并能读取当前群里的其他成员消息。一位请求失败会留下错误状态并继续下一位；主动停止会停止余下成员。

最左侧窄栏用图标和小字显示「聊天」「日记」「待办」「信件」「收藏」，底部为「设置」和个人头像。聊天、日记、待办、信件、收藏、设置是平级主页面，小窗口中主功能图标可上下滚动，底部设置和个人入口固定；日记含普通日记/小秘密分类，待办单独显示状态筛选。切换后保留各页的搜索、筛选、所看详情和列表位置，回到聊天保留会话、草稿及阅读位置。这些界面状态在当前资料库的本次打开期间保留，不代表跨设备同步。暂未接入电脑版的朋友圈等功能不显示空入口。

聊天页为图标导航、会话列表、聊天区三列；日记、待办、信件、收藏、设置使用导航右侧的完整主区域，不显示聊天输入框或聊天列表。「常用」默认收起，为聊天留出宽度；宽窗口按需展开右侧面板，窄窗口打开同样的功能窗口。聊天顶部头像/名称打开对话资料，保留角色与模型设置、用户笔记、导入记忆/设定和群内共同记录。资料中的笔记保存后会提供给对应 TA，目前没有模型自动整理或写入手机记忆的功能。

「常用」中的搜索仅查找当前对话的正文，按字面匹配、不区分大小写，显示最近 50 条匹配及附近文字；不搜索思考、其他对话、日记或秘密。点击结果回到原消息并短暂标记位置，切换对话清空搜索。最近附件列出当前对话最近 24 项图片/录音，点击回到原消息查看或播放；不包含未发送草稿。这些操作不调用模型、不发送消息，不改变原始记录。

最左下角头像是个人入口，点击后展开菜单，可进入「设置」或「切换资料库」；导航栏的齿轮也能直接打开设置。扫码接收、手机 ZIP 导入、电脑备份导出/恢复位于「设置 → 数据与备份」，不占用会话列表。这里是本地资料入口，不是账号登录；各位 TA 的模型配置仍在对应角色设置中。0.7 及以前预览版的这些数据入口直接位于左侧。

备份预览/确认、扫码配对、图片放大和角色配置仍使用临时对话框。取消或关闭备份操作后保留设置页，直接点聊天图标可回到原对话。日记/待办归档只在首次进入相关页面时读取，并在当前资料库内缓存已按可见性规则整理的浏览对象；不会提前扫描其他资料库。

## 发送图片与播放录音

输入框左下「＋ 图片」选择本地 PNG/JPEG，每条消息最多 4 张。也可以把本地 PNG/JPEG 拖到聊天区域；若系统当前拖拽动作为移动，会提示按住 `Ctrl` 复制拖入，避免影响原图。复制截图或本地图片后，在消息输入框按 `Ctrl + V`，或点「粘贴图片」添加。只在主动粘贴时读取剪贴板，不监听或定时读取；普通文字仍走文本粘贴，模型/Key 等其他输入框不接入图片快捷键。图片链接、网络共享路径和任意自定义数据不会作为图片抓取或解析。当前不支持 GIF/WebP 文件发送。

拖入和粘贴都只加入草稿，不自动发送；发送前可预览、移除。未发送图片跟随各对话草稿保存，重启或导出电脑备份后仍保留。添加时先检查格式、体积和尺寸，最长边缩到 1600 像素，转为 JPEG 并去掉原文件元数据；透明区域变白，原文件不改。单个源文件最大 20 MiB/2400 万像素，剪贴板图片同样限制 2400 万像素，处理后不超过 4 MiB。读取失败、超过四张或添加期间切换对话不会悄悄发出消息。

每位 TA 的「角色与模型设置 → 这个模型支持看图」默认关闭；请确认接口和模型支持兼容 Chat Completions 的图片输入后开启。修改接口地址/模型名会把这个开关关闭，需重新确认。群聊按每位成员分别构造请求：开启看图的成员收到用户图片，文本成员仅收到文字与未发送附件的说明；全部成员未启用看图时，不会把带图草稿当作纯文字发出。

**开启看图后，近期聊天中的用户图片会随后续请求发送到该 TA 配置的模型接口**，不只本次新选图片。每次最多 8 张、JPEG 字节合计不超过 12 MiB，优先最近图片；缺失、不可解码或超限的图片会在请求文字中说明未附入。助手附件、其他对话图片、原始归档和录音都不会自动上传。模型仍可能看错内容；开关只控制请求格式，不能替服务商验证能力。

消息中的录音有「播放录音 / 暂停录音 / 继续播放 / 停止」。仅在用户点播放后用 Windows Media Foundation 本地解码、Java Sound 输出，不调用模型、不请求麦克风、不自动播放；同时只播一段，切换对话/资料库或退出会停止。WAV、MP3、AAC/m4a 的合成样本已实际解码验证；不同 Windows 媒体组件、设备和编码变体仍可能不支持，错误时显示提示并保留原文件。本轮新增本机 WAV 录音与转写，流程见下节；模型语音回复、音量/进度拖动与后台电话仍未接入。

接口格式参考：[Chat Completions 图片内容](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)；Windows API 参考：[Media Foundation Source Reader](https://learn.microsoft.com/en-us/windows/win32/medfound/tutorial--decoding-audio)。这些文档用于核对接口，不代表所有第三方中转都支持相同能力。

### Enter 与中文输入

聊天输入框 `Enter` 或小键盘回车发送，`Shift+Enter` 换行，也兼容 `Ctrl+Enter`。空白草稿、附件处理/录音/转写期间、模型正在回复时不会重复发送。保留输入法组合范围，组词期间回车交给输入法；同一次回车按住重复不会变成发送，需松开再按。自动化已覆盖提交后的中文、多行、快捷键、按键重复与组合状态决策；真实 Windows 中文输入法选词仍需现场核对。

### 录音、转写与发送

1. 在聊天底部点「录音」才打开默认麦克风，点「结束录音」保存为当前对话草稿，也可「取消录音」。最多 120 秒，16 kHz/16 位单声道 WAV；不足半秒不保存。录音设备读取/停止在后台线程进行，停止不等待设备读取，退出会关闭麦克风并放弃尚未完成的录音。
2. 完成后可以试听。录音不会自动上传、转写或发送。已完成的语音草稿按对话保存，重启、电脑备份和恢复后保留；进行中的录音不保证在崩溃后恢复。
3. 从「设置 → 语音转文字」填入支持音频转写的基础地址（包含 `/v1` 等服务商要求的路径）、识别模型名和 Key。语音 Key 使用独立的 Windows DPAPI 项，与聊天 Key 隔离，留空保留已存的语音 Key。服务与模型需要使用者确认可用，不会自动沿用手机的权限或 Key。
4. 点「转写录音」只上传这一个本地 WAV；界面显示识别地址。采用 `POST /audio/transcriptions` 的 multipart `file`、`model`、`response_format=json`，读取返回对象的 `text`，参见 [OpenAI 官方转写接口](https://developers.openai.com/api/reference/resources/audio/subresources/transcriptions/methods/create)。这是兼容格式，并非所有中转或聊天模型都支持转写。
5. 核对或编辑「语音转写文字」，也可以自行填写语音文字。再次点击发送键或主消息输入框的 Enter，才将文字和本地录音附件加入聊天；单聊/群聊模型只收到文字，不上传录音字节，群成员沿用原有逐人上下文。转写编辑框的 Enter 仍用于换行。

转写失败或取消会保留录音草稿，可重试。发送前没有可用转写/人工填写文字时会提示并保留草稿。识别结果限 20000 字符，网络响应有大小和时间限制；拒绝重定向，错误不会回显服务器原始正文。HTTP 默认禁止，明确确认风险后只允许当前语音地址；电脑备份恢复会关闭该权限，Key 不进备份。录音/转写期间禁止切换对话或资料库，防止附件串入另一段聊天。

本轮没有真实开麦、播放扬声器或调用外部识别服务：录音使用合成麦克风/音调测试，本机 HTTP 服务验证上传、失败/取消、群聊正文及原录音保留。实际麦克风、设备听感、真实识别服务与 Windows 输入法需用户回电脑旁后验收。当前不包含实时电话、自动听写、TA 语音回复或手机历史录音重新转写。

## 导入手机资料

### 扫码传输

1. 手机与电脑连接同一 Wi-Fi；电脑点左下角个人区域，进入「设置 → 数据与备份 → 扫码接收手机」，选择对应网卡的局域网地址，生成临时二维码。
2. 手机更新到 0.41.127 后，打开「设置 → 数据与备份 → 迁移到电脑」，扫描电脑上的码。相机只在点击扫码后请求权限；也可在电脑复制配对码，再到手机粘贴，无需相机。
3. 手机显示电脑名称、地址、六位核对码及发送范围。当前只支持**整份 Cleos 备份**，含私聊、群聊、记忆、日记（包括小秘密）、信件和媒体，不含 API Key。确认后，电脑还会再询问是否接收；核对两端数字后点击同意。
4. 手机整理并发送，完成后电脑显示原有的备份预览；预览不等于导入，最后确认才建立独立资料库。手机资料不变，原电脑资料保留。

二维码包含临时凭证，请勿分享；5 分钟内有效，完成一次认证后不接受第二台设备，拒绝或失败需重新生成。电脑只在此接收窗口内监听所选局域网地址，关闭就停止；手机传输时留在此页，切后台或离开会取消。暂不支持跨互联网、IPv6、断点续传、选择单个 TA 或双向同步。访客 Wi-Fi 的设备隔离、代理虚拟网卡及系统防火墙可能阻止连接；可切换正确网卡或继续用文件导入，不修改系统安全设置。

连接使用 TLS 1.3。手机只信任当前二维码固定的临时证书指纹，不依赖公网证书、不跳过全局证书校验、不修改系统信任库。电脑还校验随机配对凭证并等待人工同意；所有备份内容只在此连接上传输，不经云服务、模型或 MCP。接收长度和 SHA-256 校验后才交给 ZIP 预览器。源 ZIP 最大 2 GiB，传输后仍受下述导入限额约束。

传输成功、取消或失败后清理临时缓存；异常退出留下的电脑接收缓存在下次打开该工作区时清理，手机过期发送缓存会在下次准备传输时清理。已导入资料库中的原始备份归档会保留。

### 文件导入

1. 在手机 Cleos 的备份功能中导出 ZIP，把文件复制到电脑。
2. 电脑从「个人菜单 → 设置 → 数据与备份 → 导入手机备份」选择 ZIP；预览记录数量、备份时间、缺失附件提示和资料库名称。
3. 确认后建立单独资料库。左下个人菜单的「切换资料库」可以随时切回「我的电脑资料库」。取消预览不写入资料。

目前接受 `cleos-backup` 格式 1–15；已用当前 Android 格式 15 的真实序列化器生成合成样本验证，并覆盖旧版单 TA 回退。尚未逐个验证所有历史版本的真实手机备份。高版本、损坏记录和不安全文件路径会拒绝导入。

| 资料 | 当前处理 |
| --- | --- |
| TA、角色设定、模型地址与模型名、各 TA 对应的用户头像 | 导入，手机 Key 不包含在备份内；HTTP 授权不沿用 |
| 私聊、群聊、草稿文字、历史发言者、分离的思考与中断内容 | 导入；已离开的成员保持历史身份，缺少可用成员的群保留只读 |
| 记忆、世界设定、私聊摘要、群内共同记录 | 可查看；私聊使用对应 TA 的记忆摘要及匹配的启用设定，群聊仅使用群内共同记录，不带入私聊记忆 |
| 图片与来源声明 | 本地预览及放大查看，保留版权来源文字；用户图片可按模型看图开关随请求发送，遵守上述限额 |
| 录音 | 手机原文件与已有转写保留，可点按本地播放；新录音/转写/发送限本机录制的 WAV，模型语音回复尚未接入 |
| 日记、待办 | 从原手机归档中只读浏览，包含日记图文顺序、署名、日期、待办备注和完成状态；尚不能编辑、创建或设提醒 |
| 信件、收藏 | 从原手机归档中只读浏览，支持正文/备注搜索与 TA 筛选；收藏保留独立片段、历史署名、图片来源和本地录音；尚不能寄信或增删收藏 |
| 动态、表情包、完整工具与通话记录、草稿附件等 | 完整原始 ZIP 和 JSON 归档，尚未提供全部桌面浏览和编辑功能；工具结果不作为普通聊天正文传给模型 |

同一份 ZIP 再次导入会打开已有资料库，保留导入后在电脑上新增的聊天，不重复覆盖。另一次导出的 ZIP 是另一份快照，会建立新资料库，目前不合并差异、不回写手机，也不属于同步。导入本身不会调用模型。

### 查看日记与待办

最左侧「日记」「待办」图标打开当前资料库对应的手机快照。日记、小秘密、待办分开浏览，支持当前分类搜索；日记保留文字和图片的排列顺序、日期与作者，待办可按未完成/已完成筛选并查看备注。普通电脑资料库若尚未导入手机资料，会显示导入指引，不会扫描其他资料库。

小秘密默认不出现在普通日记列表中。自己的小秘密可在对应分类查看；TA 尚未分享的小秘密只显示公开提示和已允许的摘录，不解码、搜索或预览隐藏的标题、正文、图片。询问 TA 是否愿意分享暂需回到手机版，电脑版不会自行解锁。全部日记与待办保持本地查看，不加入聊天模型上下文。

这是**备份时的只读快照**，不会更新手机、勾选待办或触发提醒，也不会创建新日记。原始手机 ZIP/JSON 与桌面聊天不改写，电脑备份往返恢复后仍可浏览。只在打开浏览页时读取当前归档；归档缺失、不匹配、超过 32 MiB 或版本无法识别时显示错误。两类记录各限 30000 条；字段异常的记录计数提示并保留原归档，不猜测其可见性。长篇内容和标题有界面显示上限，提示完整原文仍在归档；图片复用本地安全预览，不抓取外部地址。

导入会核验 ZIP 路径、数量和大小，提取媒体时检查 CRC；复制的原始备份还会核对 SHA-256。资料先写入新的独立目录，完成校验与读取后，最后才登记到资料库列表；不需要重命名含有媒体的整个目录，避免 Windows 文件占用导致这一步失败。失败时不登记新资料库，原来的电脑聊天保留，提示失败所处阶段并清理本次未登记目录。强制退出或外部文件占用可能留下未登记文件夹，不会自动把它当作可用资料库。最大 ZIP 为 2 GiB，展开总量 4 GiB、JSON 32 MiB、单个媒体 128 MiB，最多 30000 项。图片预览另限制 20 MiB、2400 万像素，超过预览限制仍保留原文件。

### 查看信件与收藏

左侧「信件」「收藏」进入与聊天平级的主页面，可搜索当前分类正文、署名或备注，按 TA 筛选。信件分为全部、收到的、寄出的和草稿；同一资料库的本次打开期间保留搜索、筛选、所看详情及列表位置，返回聊天保留草稿和阅读位置。

这是**备份时的只读快照**。TA 的信仅在送达时间不晚于备份时间时显示；尚未送达或缺少送达时间的来信在正文解码、搜索与预览前排除，不会因电脑时间推移自动出现。你的寄出信和草稿可查看。未读标签表示备份时的状态，打开不会写已读状态、不寄信，也不触发通知或后台任务。

收藏使用保存时的独立片段，不依赖原聊天仍存在；按原顺序保留历史署名、时间、消息间隔、备注、图片与来源声明、录音原文件。本地图片可放大，录音可按需播放；离开详情或页面停止播放。图片来源地址仅作为文字保留，不抓取远程内容。已取消的收藏排除，异常条目显示跳过数量；完整原文保留于归档。尚不支持新收藏、改备注、取消收藏或跳回原消息。

信件与收藏各限 30000 条，单篇信和单条收藏正文显示上限为 200000 字符，收藏备注 20000 字符，超长会提示。无对应字段的旧备份显示空列表。原始归档缺失、大小超限或与资料库不匹配时显示错误并保留聊天。两类资料不进入聊天模型上下文，不写手机或原始归档；当前使用桌面资料格式 4 与备份格式 1，恢复电脑备份后可继续查看。

## 本地数据与 Key

### 电脑备份与恢复

从「个人菜单 → 设置 → 数据与备份 → 电脑备份 → 选择位置并导出」保存**当前这一份资料库**的 TA、角色与模型地址、私聊/群聊、未发送草稿、笔记、记忆、折叠思考、中断内容和本地附件。若来自手机导入，还会带上完整原始手机 ZIP/JSON（包括其中的日记、小秘密等尚未适配到桌面界面的资料）。其他资料库需要切换后分别导出，不会扫描或打包整个工作区。

备份为**未加密 ZIP**，包含私人资料，请妥善保管。桌面 `keys.dpapi`、`.bak`、锁文件与其他资料库不在导出范围；HTTP 权限不随备份恢复。ZIP 中的逐文件 SHA-256/CRC 用于检查损坏，不是加密或来源认证。导出先写同目录临时文件并完整校验，再改为目标文件名；已有目标文件不会覆盖，请选择新的文件名。可以取消导出，正常取消/错误会清理本次临时文件；程序强制退出时保存位置可能遗留 `.cleos-export-*.partial`，它不是可用成品，可由用户确认后删除。

在另一台电脑的「电脑备份 → 恢复电脑备份」选择这份文件。预览时间、数量、缺失附件和原始归档范围后，再「确认恢复」，建立独立资料库。原资料保留；同一份电脑 ZIP 再恢复时打开已恢复的资料库，保留之后新增的聊天。已有 Key 仍按当前电脑的接口地址存储；换电脑需自行配置 Key，恢复本身不会请求模型。

当前仅支持电脑备份格式 `cleos-desktop-backup` 版本 1，内含桌面资料格式 1–4。最大 ZIP/展开量各 8 GiB，最多 30010 个条目，桌面/原手机 JSON 各 32 MiB、清单 8 MiB、单个媒体 128 MiB、内嵌原始手机 ZIP 2 GiB。检查固定文件范围、路径、大小、摘要和 CRC，恢复到新独立目录，校验与读取成功后才登记资料库。已有缺失附件会保留缺失提示；手机原始归档缺少或不符时拒绝导出，避免静默漏掉未适配的内容。

**电脑备份目前不能导回手机版，也不是双向同步。** 手机原始 ZIP 是首次迁移时的快照，不包含后来在电脑上新增的聊天；电脑新增内容在外层 `library.json` 中。源码、打包和合成测试验证不能替代真机扫码、大资料量、U 盘/网络盘和实际 Windows 文件对话框的现场验收。

### 资料位置

- 默认资料库：`%LOCALAPPDATA%\Cleos\Desktop`。这里的角色、私聊、群聊、草稿和笔记与手机端分开保存。
- 原电脑资料库仍在根目录 `library.json`；导入资料分别位于 `libraries/library-<id>/`，其中 `media/` 放附件，`source/phone-backup.zip` 与 `source/backup.json` 保留完整原始备份。这些文件包含聊天等个人资料，应按私人备份保管。
- `workspace.json` 记录资料库列表与当前选择；`library.json` 为可读的聊天资料，替换写入前保留 `.bak`。工作区和资料库都有文件锁；损坏或未知版本不会自动覆盖为空白资料。桌面格式 1–3 自动读入格式 4，新增独立语音草稿和识别配置；旧程序不支持格式 4，请使用 0.13 及以后版本继续打开。升级前可在旧版导出电脑备份。
- Key 保存到 Windows DPAPI 加密的 `keys.dpapi`，绑定当前 Windows 用户，不写进聊天资料。同一完整接口地址共用 Key，移除会影响这个地址下的其他 TA。
- Key 输入框不回显已有 Key；留空保留原 Key。HTTP 默认禁止，明确确认风险后才允许该接口明文连接。网络请求不会跟随重定向转发 bearer token。
- 退出时保存草稿；上次未结束的回复在重启后标为中断，保留已收到的正文和思考内容。

开发与验收可以使用 `--data-dir <独立目录>`，或设置 `CLEOS_DESKTOP_DATA_DIR`，避免接触默认资料库。

## 预览版边界

已接入真实 HTTP/SSE 文字请求、本地持久保存和基础半透明玻璃界面。桌面渲染没有直接复用 Android 的 RuntimeShader，折射、壁纸和手机主题迁移仍需后续适配。

外部服务实测需要使用者自行配置对应 Key；自动化测试只向本机合成接口发送合成消息，不读取手机或其他程序中的凭证。图片拖放/粘贴使用注入的合成文件、像素和事件验证，并已检查 Compose 窄窗渲染。0.7 的真实 Windows 窗口已用独立合成资料库检查日记图文、小秘密显示边界、搜索、待办筛选与返回聊天。原生选图框能打开，自动化工具未能稳定聚焦其输入框，完整文件选择仍待手动验收；真实拖拽、系统剪贴板、扬声器听感和实体手机扫码也仍待现场验收，不能把合成测试表述为已通过这些检查。

持续同步、手机历史录音重新转写、工具、通知、语音通话和一起听音乐属于后续阶段。当前接口面向兼容 Chat Completions 的服务，不把原生 Anthropic 或 Responses 接口当作已支持。手机功能不会因导入而自动在电脑上启用。

## 源码构建

在仓库根目录，用含 `jpackage` 的完整 JDK 21 运行：

```powershell
.\gradlew.bat :desktop:test
.\gradlew.bat :desktop:run
.\gradlew.bat :desktop:createDistributable
```

便携目录位于 `desktop/build/compose/binaries/main/app/Cleos`。Windows 安装程序可通过 `:desktop:packageMsi` 另行打包。Android Studio 自带的部分 JBR 没有 `jpackage`，能编译并不等于能生成桌面发行包。

现阶段传输、上下文和存储放在桌面模块内独立分层，后续迁移手机业务时再逐项提取共享模块；没有为了桌面原型直接替换手机请求器或数据库。

# Cleos 0.41.72 候选修复

状态：本地修复候选，未发布。版本号 0.41.72，versionCode 149。

## 设定批量删除

- 在 TA 的设定页增加多选入口，可按条选择、按书选择、全选当前搜索结果和清空选择。
- 搜索结果的全选只影响当前结果，已选但未显示的条目仍保留在选择中；删除数量按全部所选计算。
- 删除前用玻璃实验室的卡片材质显示确认框，说明 TA、条目数量及不可撤销。
- 大列表按每批最多 500 个编号删除，整个操作使用 Room 事务；SQL 同时限制 TA，避免超过 SQLite 参数限制或删除其他 TA 的设定。
- 返回先退出多选；多选时点条目用于选择，不打开编辑页，也不改变条目启用状态。
- 此功能帮助清理误导入内容，并不改变原有导入解析规则。

## 工具请求拒绝后的恢复

- 删除工具拒绝的整个应用运行期间缓存。一次工具请求被接口明确拒绝时，只对当前回复降级；后续聊天、电话和后台唤醒重新按已开启的权限提供工具。
- 提示改为“接口拒绝了本次工具请求”，不再把一次拒绝描述成模型永久不支持工具。
- 仍然只允许明确的能力拒绝触发降级；普通 HTTP 错误、参数格式错误、工具历史错误不会因此移除工具。
- 未扩大工具权限，未自动执行额外工具，未添加模型名白名单。
- 真正不接受工具的接口可能在后续每轮先拒绝一次工具请求，再使用纯文字降级；这比把一次路由拒绝当成永久能力判断更保守，仍可由用户关闭不需要的工具。

## 尚未确定的问题

- 用户反馈 Claude 在其他客户端可以调用工具，但 Cleos 显示不支持。目前没有该用户的接口域名、完整模型名、版本号及实际错误响应，不能确定其首次拒绝的原因。
- 当前客户端使用 OpenAI-compatible chat/completions 格式。原生 Claude 使用 tools/input_schema 和 tool_use/tool_result，协议或转发适配差异需要拿具体接口核对。参考：https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview
- 不将上述缓存修复宣称为已经解决该用户的 Claude 接口问题；还需真实接口复测。

## 照片分享需求

- 用户希望 TA 自主搜图或生成图片并分享。
- 现有 publish_feed 工具只发文字，尚未提供完整的模型搜图/生成/保存/发送链路。本版不实现该新增功能。
- 后续设计需区分网络照片和 AI 生成图片，保留来源并对接实际可用服务；不能仅返回文字地址就称为已发送图片。

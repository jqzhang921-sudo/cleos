# 0.41.64：生活资讯与 TA 自主选题

- 朋友圈顶部三点菜单新增「想看什么」，使用玻璃实验室的卡片材质；在手动逛逛面板及主动逛朋友圈设置中也可打开。
- 可以多选猫猫宠物、旅行风景、美食厨房、科技数码、科学太空，也可同时保留一条自选 RSS / Atom。所有 TA 共用阅读范围，兴趣提示可留空跟随角色设定。
- 选项和地址是草稿，只有「保存」才应用；取消不会修改设置。已有订阅及兴趣继续保留，未保存新分类时保持原来的自选订阅或 NASA。
- 「检查来源」只读取公开订阅，逐项显示近期文章数量，不调用模型、不发帖、也不保存草稿。
- 手动资讯和已开启的后台资讯使用同一份选择，均由 TA 按性格与兴趣挑一篇，也可以选择不发。选题范围改变不会自动开启后台阅读或发帖。
- 各方向轮流进入候选列表，避免更新快的科技源占满。手动最多 12 篇，自动最多 6 篇；过滤该 TA 已分享的链接和重复链接。
- 每个方向可以使用备用来源；单个方向不可用不影响其他方向。并发最多 3 个方向，每方向最多等待 25 秒，成功结果缓存 5 分钟。
- 仍只读取最近 14 天的标题和有限摘要，TA 用中文分享并保留原来源，不假装看过全文或图片。自动阅读没有新资讯时仍可回应朋友、分享日常或安静。
- 手动日常上限 80 字、资讯上限 600 字，支持安静结果并阻止无效来源及重复发布。生成中若角色或阅读偏好改变，本次结果不发布。
- 备份增加阅读分类，旧备份继续兼容；不涉及数据库迁移。

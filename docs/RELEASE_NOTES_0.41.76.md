# Cleos 0.41.76

- 新增「找照片」能力：在设置的「能做的事 → 聊天时」开启后，支持工具调用的 TA 可以从 Openverse 公开图库寻找猫、风景、美食等照片，再选择一张发成聊天图片卡片，无需另外填写 Key。
- 图片卡片复用玻璃卡片材质，保留标题、作者、来源和许可；来源与许可可点击查看。图片下载到本机，跟随聊天备份、恢复和删除。
- 先搜索再分享，只接受当前聊天最近找到的真实照片编号。限流、断网、结果过期或图片无法保存时明确提示，只有实际保存和写入聊天后才确认发送。
- 「找照片」默认关闭；暂不在后台唤醒、电话或朋友圈自动搜图。这里是图库预览分享，尚未接入 AI 生图或朋友圈附图发布。
- 只下载 Openverse 的小图代理，支持 PNG、JPEG、WebP，单张最多 2 MiB；与 MCP 图片共用每轮回复最多 6 张的限制。不下载模型提供的任意 URL。

公开图库接口与字段参考：[Openverse API](https://api.openverse.org/v1/)。第三方图库的网络可达性与限流可能影响找图结果。

验证：578 项单元测试最终通过（0 失败、0 错误、0 跳过），release 编译、vital lint、修改格式检查与签名校验通过。新增 17 项测试覆盖候选来源、当前聊天范围、过期、数量与体积限制、限流、下载及保存失败、取消和元数据保存。旧诊断日志并发测试首次期望 120 条实际 119 条，单独复跑及完整复跑均通过，具体偶发原因尚未确认，未修改诊断实现或降低断言。

公开图库查询实际返回 200 和 6 个候选，小图接口返回 WebP 图片。已覆盖安装到手机，确认 0.41.76（153）并成功启动，原始安装时间保留。未发送测试聊天或调用付费模型，TA 实际选择和手机图片卡片完整流程尚待试用。安装包比 .75 增加 16 KiB。

# 随手本：磨砂页片与翻阅

2026-11-06。参考 LeafThrough（https://dmtrbrl.github.io/leafthrough/vue.html）的跟手翻页和层叠光影；沿用 Cleos 的主题色与磨砂玻璃，不引入泛黄纸张、牛皮封面或大字号。原生 Android 实现，不直接把私人随笔发给网页。这个 goal 本轮只在本地推进，不连接或安装用户手机。

## 第一阶段：能找、能读、能回来

- 紧凑目录展示标题、类型、时间与少量摘要；保留搜索和筛选。
- 点击篇目进入独立阅读区，短文一页、长文按实际文字排版拆页；左右翻阅可抵达其他篇目，目录可直接跳转。
- 页码同时标明当前篇目与篇内页码；当前 TA 的阅读位置保存为篇目和字符位置，字号/窗口变化后重新分页，旧条目插入时不按旧页码跳错。
- 位置是设备本地 UI 信息，按 TA 身份和条目时间隔离；不改原文、不改变写作调度/次数，不新增模型请求。

## 第二阶段：轻柔翻动与主题一致

- 内页使用主题色磨砂底，足够遮住背面文字；控件沿用玻璃。
- 跟手翻动配轻微倾斜、弧形边缘、层叠与渐变高光阴影。先采用原生轻翻页；不宣称与参考的 WebGL 纸张网格弯曲完全相同。
- 保留前后按钮及减少动态效果；在原生页中保留文字选择/复制、来源跳转、问题查阅和删除确认。

## 第三阶段：验证和交付

- 分页边界测试覆盖中英文、换行、emoji、大字号与极小可用高度，保证拼接仍等于原文。
- 用合成资料做离线原生验收：目录、筛选、前后翻、直接跳转、旋转/字号变化恢复、进程重开、删除、所有者切换、深浅主题与减少动态效果。
- 原始数据库、设置和图片保持；清理精确的合成资料并关闭自有模拟器。
- 记录包、验证结果与限制；手机未连接就明确报告尚未安装。

## 后续另行细化

连载“合册”需要可靠的系列和章节关系。目前数据只有独立标题与正文，不自动推断、改写或合并原内容。后续可增加用户手动归册及章节顺序；不将其伪装成本轮已实现的功能。

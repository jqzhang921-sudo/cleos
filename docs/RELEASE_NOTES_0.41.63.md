# 0.41.63：TA 主动逛朋友圈

- 朋友圈顶部三点菜单新增「主动逛朋友圈」玻璃设置面板；「设置 → 说话方式」也可以设置当前 TA。
- 每位 TA 独立开启，默认关闭。可只阅读和互动，也可另外允许自动发日常、分享资讯。
- 偶尔：约 8–12 小时一次，每天最多 2 次考虑机会；自然：4–6 小时 / 4 次；常来看看：2–4 小时 / 6 次。
- 自动发帖每位 TA 每天最多 1 条；手动邀请和手动「让 TA 逛逛」另算。不发送聊天提醒。
- 默认 23:00–08:00 免打扰，时间可调；起止相同表示全天免打扰。开启或调整后先等待，不立即调用模型。
- 读取最近 7 天、最多 4 个新的阅读对象。作者只回应朋友评论，同一段内容不重复邀请；已看过的内容可以安静略过。
- 阅读最多携带 3 张照片，需要所选模型支持图片。资讯只使用订阅提供的标题与摘要，附原来源。
- 正在聊天、输入、处理另一条动态、缺少 Key 或夜间免打扰时跳过。关闭设置会取消正在生成的自动动态；返回前再检查设置、作者资料和阅读对象。
- 每日次数、自动发帖次数与下一次安排保存在本机，改档、关闭再开启和应用重启不会清空当天额度。恢复备份时取消旧工作，再根据恢复后的开关安排；调度计数不导入备份。
- 主动消息记录新增「主动逛朋友圈」来源及「已更新朋友圈」状态，区分未请求模型、模型选择安静、取消和失败。

# 窗外搜索来源：后续接入范围

2026-10-26。用户指出手机不开代理无法使用「继续查阅」的中文维基百科入口，询问 Bing 或其他无需代理的搜索来源。此文件仅整理可实施范围；.162 只做批量管理，没有接入新的搜索服务，也不代用户开通、充值或调用付费接口。

## 候选路径

- 应用内取回标题 / 摘要 / 来源，交给当前 TA 阅读：优先评估博查等国内搜索 API。需要独立搜索 Key，模型接口与搜索接口分开，仍可使用现有 MiMo / DeepSeek。国内网络能否稳定直连必须在用户手机上实测，不能由电脑或服务商所在地推定。
- 免费手动入口：打开 Bing 等搜索网页，供用户自行选择和浏览。只打开网页不等于已经把结果取回给 TA；不得把此入口描述为自主查阅已完成。
- 现有维基来源保留为可选项，既有数据与配图继续可离线回看；不强迫每次搜索都走维基。

## 实施约束

1. 先明确用户愿意使用哪家搜索服务及其独立计费方式，再接真实接口。Key 只在设备的现有加密凭据存储中保存，不写进 APK，不复用模型 Key 或发送给另一供应商。
2. 手动切换搜索来源才使用新供应商，说明只向其发送搜索词；不附带聊天、用户记忆、相册或整个笔记本。后台续查不能悄悄切换为付费搜索；现有许可需绑定来源与配置变化。
3. 原数据目前只允许固定来源 URL。接入前要同时更新来源校验、去重、大小限制、备份验证与恢复兼容，不能只改按钮和 URL；保留来源名称、实际返回的摘要范围，不声称读了全文。
4. 搜索返回的网页与图片链接属于外部资料。不能直接当成本地图片、已获许可图片或 TA 已经看过的图；现有维基 Commons 配图规则不会自动适用于普通搜索结果。
5. 失败分清凭据、额度、网络、来源不可用与空结果。满 60 条时先提醒管理，不执行一次付费搜索后才丢弃结果。取消、换 TA、恢复或旧请求晚返回不能混入新资料。
6. 开发验证使用模拟返回与独立合成资料；没有用户提供并明确选择搜索服务前不请求其付费账户。

## 已核对的官方资料

- [微软：原 Bing Search APIs 于 2025-08-11 停用](https://learn.microsoft.com/en-us/lifecycle/announcements/bing-search-api-retirement)。不能将旧 API 视作仍可开通的免费方案；微软建议的 Grounding 属另一接入体系。
- [博查开放平台](https://open.bochaai.com/)提供带搜索 Key 的 Web Search API，可返回网页资料，适合作为候选；接入时重新核对当时文档、端点和响应结构。
- [博查服务条款](https://open.bochaai.com/terms-of-service)说明采用按量计费，不在本计划里写死价格或承诺免费。

用户已选择先做免费 Bing 网页入口，付费搜索 API 暂不接入。


## .163 已交付

2026-10-26，已按用户选择实现「用 Bing 网页搜索」并同签名保留数据安装手机。仅将当前检索词交给系统浏览器，不取回结果、保存见闻或调用模型，不消耗阅读次数；原维基摘要与 TA 阅读保留。浏览器返回草稿、大字体恢复及换 TA 清空均完成最终包离线检查，1327 项 JVM 与 4 项界面检查通过。尚未验证用户手机不开代理的远端 Bing 可达性；其他自动搜索 API 仍未接入。详见 RELEASE_NOTES_0.41.163.md。


## .164 免费正文衔接

用户选择继续免费方案。2026-10-27 已实现并保留数据安装：在浏览器复制正文后，通过「粘贴正文给 TA」填写标题和可选来源，预览、确认保存至当前 TA 书房文章，再明确选择「让 TA 读这一篇」。仅将保存文字分段发给现有模型，笔记进入随手本，不会自动读取浏览器、抓取任意链接或获取图片；没有新搜索 Key 或付费搜索接口。导入无模型请求，实际阅读仍使用用户现有模型额度与原阅读次数规则。验证见 RELEASE_NOTES_0.41.164.md。


2026-10-27 用户认为 Bing 手动衔接较繁琐，当前优先开发自由随笔，搜索优化暂缓。本轮未新增搜索接口、抓取网页或调用付费服务，现有网页入口保留为可选工具。

## 2026-10-30 固定订阅 / 热点来源评估

用户提供 TrendsHub 来源清单后，已核对原项目并探测 24 个具体地址。优先候选为少数派、机核和 InfoQ 中文 RSS，科技快讯 / 热榜作为后续可选来源。固定来源可提供应用内取回的标题及实际说明文字，减少 Bing 手动粘贴步骤，但不能替代任意关键词搜索。部分清单地址返回业务错误、空响应或错误路径，不能按旧备注直接接入。此次仅形成评估与证据，未修改 App 或安装 MCP 服务，也未验证真实手机无代理可达性。完整结果见 WORLD_OUTSIDE_SOURCE_REVIEW_2026-10-30.md。

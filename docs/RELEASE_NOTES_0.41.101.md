- 长按群里的文字、语音、图片或空的失败 / 取消回复，打开玻璃操作卡。TA 回复可删除单条，也可以删除整轮；用户发言是该轮起点，删除时包含这一轮 TA 回复。原先没有回复的一条用户消息可单独清理。
- 确认框展示本次条数、所选内容、附件数及关联小本本条数，取消不改变记录；回复 / 通话或转写过程中暂不允许删除。确认前后内容、来源笔记、群身份或恢复代次变化时要求重新核对，避免旧确认删除新数据。
- 单条删除同步更新轮次的成员与完成状态，最后一条 TA 回复删除后移除空轮次、保留用户原话。整轮删除清理起始发言与该轮所有回复 / 占位记录；同一起始消息关联多个历史轮次时一并纳入确认。
- 已整理的小本本内容保留，原消息链接解除并显示原消息已移除。工具记录随消息清理，已执行的操作不撤销。附件仅在没有其他聊天、草稿、头像、日记、朋友圈、表情包、收藏或外观设置引用时清理；无法核对引用时保留文件。
- 删除不改变群草稿、成员、轮转位置或私人聊天。删掉最后一条 TA 回复后，不会让更早话题的失败回复重新成为可重试的新话题。

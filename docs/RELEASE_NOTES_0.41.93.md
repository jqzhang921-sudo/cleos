# Cleos 0.41.93

- 群聊新增用户发图入口：每条最多 3 张，使用系统选图器；发送前可预览、看大图或移除，图片草稿重启后保留，支持不写文字直接发送。
- 成员各自接收本群实际图片，优先处理用户这一轮上传的图。图片与文字保留实际作者，群外消息及未完成的回复正文不会混入请求。
- 接口明确拒绝图片时，仅该成员本次去掉图片并改用文字及来源说明，显示提示；不会将其他成员或后续请求一并判成不支持图片。网络错误或已开始输出的请求不自动重发。
- 图片归属与群草稿、消息、删除和备份一起管理；缺失文件会明确提示，不伪装成看过图片。沿用玻璃实验室的卡片材质。

数据库升级到 37，在群表新增可空的图片草稿字段；备份升级到格式 7，保留读取旧备份的兼容性，旧 App 需更新后才能恢复新格式备份。

750 项单元测试、正式签名构建及发布必需 lint 通过。生成的 36→37 迁移 SQL 验证了旧私聊、群聊、小本本保留，以及草稿转为消息时的事务回滚和跨群隔离；本地真实 HTTP 测试确认拒绝后的重试请求不含图片字段。

OPPO 实机覆盖安装并验证选图、预览、移除、重启保留草稿、带文字发图和第二轮纯图片消息。DeepSeek 与 Claude 两轮均完成回复，首位成员正确区分两张测试图的形状与颜色。当前实机接口未拒绝图片，拒绝图片的降级分支使用合成 HTTP 响应验证。完整个人备份恢复、其他机型、长期使用及真实文本接口的降级实测仍待进一步验收。

群内语音与自主互聊尚未接入。

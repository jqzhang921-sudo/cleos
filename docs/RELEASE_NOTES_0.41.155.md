# 0.41.155：在线文库错误分辨

## 问题与行为

用户在手机检索《窄门》和「失语者」时看到相同的「没有取回可确认的文字」提示。旧界面把所有请求 / 解析异常合并，单凭截图无法确认是手机连接、来源响应还是格式核对失败，也不能推断文库没有这些作品。电脑端以这两个检索词请求固定文库 API 均得到有效候选，但候选可能只是含有关键词的其他文章。

- 区分连接失败、超时、安全连接失败、来源限流 / 拒绝 / 服务错误、格式或版本核对失败、超出大小限制；明确是查找还是取回原文未完成，不再把这些异常暗示为作品不存在。
- 正常成功但没有匹配页面沿用独立空结果状态；编辑检索词立即清除上一轮错误。界面明确只搜索中文维基文库，结果可能只是提到关键词的文章，应核对标题与正文。
- 出错后提供「用浏览器检查文库」，只打开固定公开首页 `https://zh.wikisource.org/`，不附带检索词。浏览器检查与 App 到来源的连接仍是不同路径，浏览器能打开也不能单独证明 API 可用。
- 错误提示由固定类别生成，不显示异常原始文字、响应正文、请求头或 Key。取消仍走取消分支；查询、预览、失败不保存、不扣阅读次数、不调用模型。
- 保留固定 HTTPS 来源、禁重定向、响应大小 / 深度限制及固定修订核对。没有新依赖、权限、数据表或后台工作；数据库 59、备份 24 不变。

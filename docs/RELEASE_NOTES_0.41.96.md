# Cleos 0.41.96

- 群成员面板新增「顺势接话」，默认关闭，保存后生效。普通轮转的两位成员成功回复时，TA 可根据实际话题邀请一位还没发言的伙伴补充，每轮最多多一位；可以不邀请，不强求每轮增加回复。
- @ 点名仍只请点名的人。邀请只对当前群、当前轮次和实际成员编号生效；已发言、已离群、已删除或正在别处忙碌的伙伴不能重复加入队列。
- 邀请者成功结束回复后才安排接话，邀请后接口失败或手动停止不会继续追加。单独重试、重启及备份恢复都不会产生新邀请；已经安排但未完成的成员可以单独重试。
- 接话成员沿用自己的角色、模型和本群上下文，只补充自己的发言，不能继续邀请下一位。工具与邀请记录可以查看；没有增加专门决定谁说话的模型请求。
- 设置按群保存，群界面沿用玻璃实验室卡片。开启后可能增加成员回复及其工具的模型用量，目前没有后台自行互聊。

数据库升级 38→39，仅增加默认关闭的群设置；备份格式升级为 10，保留设置、邀请记录和实际发言者，继续读取旧备份。新备份需要更新 App 后恢复。

807 项测试、正式构建和发布必需 lint 已通过。完整实机与合成测试范围见本轮验证记录；各 TA 独立音色、多人实时通话和后台自主互聊继续后续规划。

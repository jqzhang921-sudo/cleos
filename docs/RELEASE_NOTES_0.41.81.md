# Cleos 0.41.81

- 对话记录增加「私聊 / 群聊」标签。可选择 2–4 位已有 TA 建群，每位使用自己的角色设定、模型和连接配置；界面沿用玻璃实验室卡片与现有气泡材质。
- 群内消息显示实际发言者。@ 点名只请选中的成员回复；普通消息按本地顺序轮流请两位接话，后回复者能看到本轮前面的已发送内容，不额外调用一个调度模型。
- 支持停止整轮、单独重试本轮失败或停止的成员、保存输入草稿、修改群名与确认后删除群聊。重试不会重新请求已经成功的成员，停止后的晚到内容不能继续提交，重启不会自动重发。
- 群内记录独立保存，不自动带入私聊正文、私聊摘要或私密日记。成员身份使用编号区分；删除 TA 后，旧群消息仍保留名字和头像快照。第一版建群后成员固定，先支持文字交流；群内工具、图片、语音和自主插话后续另做。
- Room 数据库采用 31 → 32 的增量迁移；备份加入群、成员、轮次、消息、草稿和头像文件。旧备份仍能读取；新备份格式升级为 2，旧版应用会拒绝不支持的新格式，避免悄悄漏掉群聊。恢复中断回复后需要用户手动重试。

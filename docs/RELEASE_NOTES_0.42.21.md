# 0.42.21：相册翻看与重看记忆

## 使用变化

- 自动翻看只从这位 TA 尚未确认看过的图像中选择。没有新照片时等待，不请求模型、不占用每天共享的阅读机会；自动安排保留，以后添加照片仍能继续。
- 同一位 TA 重复导入相同图像，不会让它重新变成“没看过”；另一位 TA 的记录不影响它自己的相册。
- 手动「让 TA 看」仍可邀请重看。发送同一张图像及说明时，带上这位 TA 对它最近三次以内的确认记录，每条最多 600 字感想、200 字疑问，不携带其他图像、其他 TA 的记录或文件路径。
- 模型可以不看，也可以确认看过而不写感想。不要求它编造新评论，也不要求在聊天中提及相册。失败、停止仍退回次数，不会假记为“看过”。
- 相册显示等待新照片的说明；发送确认和翻看安排说明包含重看时使用少量旧记录的范围。

本轮不增加手机图库权限、不关联手机图集、不自动发布聊天或朋友圈。数据库 68、备份 32 保持不变，保留现有照片和感想。

## 实现位置

- `data/WorldAlbumConsent.kt`：以 TA 归属及图像哈希隔离看过记录，排除自动重复候选。
- `data/WorldAlbumScheduler.kt`、`data/WorldLibrary.kt`：调度与执行双重检查，无新图像在请求和次数预占前结束；手动重看仍走原流程。
- `ai/WorldReader.kt`：限量加入同图像历史，保留单图确认与异常修复机制。
- `ui/world/WorldAlbumPage.kt`、`WorldAlbumAutonomy.kt`：状态及发送范围说明，重复图像显示相同已确认历史。
- `WorldAlbumConsentTest.kt`、`WorldAlbumReaderTest.kt`：候选和请求隔离测试；debug-only `WorldAlbumQaActivity.kt` 验证真实 Room、调度和取消流程。

原生验收使用隔离内存数据库、合成图片与拦截器，不向外部模型发请求。完整构建、测试、界面和安装的最终结果位于本轮 `outputs/Cleos-0.42.21-album-continuity/`。

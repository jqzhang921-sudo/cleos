# Cleos 0.41.102 · 群通话玻璃记录卡

- 每轮群通话的用户转写和 TA 发言默认收进一张玻璃卡片，使用玻璃实验室的卡片材质。收起时显示时间、参与者及正在接话 / 未完成状态，点击带弹性动画展开，再次点击收起。
- 展开后按原顺序显示发言，保留「这句未完整播完」、失败或取消说明，长内容可在卡片内滚动。长按具体发言打开原有文字选择、小本本和删除操作；长按卡片标题可操作这一轮转写。
- 卡片展开动画结束后定位到这一轮，避免位于列表底部的内容落在输入框后面；不会因持续写入发言而反复抢走滚动位置。
- 按实际群、用户起始消息与轮次关联归组，不按相邻时间猜测整通电话；旧数据没有整通起止时间，本版展示「本轮」，不添加虚构通话时长。原始内容、消息编号、模型上下文和小本本来源均不重写。
- 缺少关联、成员目标不一致、插入其他话题或含图片 / 语音附件 / 工具数据时保留原气泡，防止折叠隐藏内容。删除后的卡片随实际剩余消息更新，只有转写时仍保留记录。

数据库仍为 40，备份格式仍为 11，没有新增迁移。群通话本身仍是轮流接话试用，系统音频行为与完整多轮验收继续独立进行。

验证：906 项测试、正式构建与发布必需 lint 通过。OPPO 同签名安装 .102 / 179，已有三条通话记录的收起 / 展开、展开后定位、未播完 / 取消说明、长按操作、原文字选择及整轮三条删除预览后取消均通过；没有新录音、发送消息或删除原记录。长篇内部滚动、其他机型和系统音频检查不据此标记通过。新包在桌面，.101 已归档至「旧版本」，未暂存、提交、推送或发布 Release。

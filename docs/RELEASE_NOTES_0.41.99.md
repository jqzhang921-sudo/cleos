# Cleos 0.41.99 · 群通话收尾与离线联调

- 修正刚点开始就立即挂断、任务尚未执行时可能一直留在接通界面的问题。私聊和群通话统一在任务完成时收尾，清理资源后再释放音频名额；旧通话的延迟退出只影响自己的会话，不会清除下一通。
- 转写失败、空转写、打断或超时不会提前改变下一轮的发言顺序；已保存的一轮才推进先后顺序。中途取消会完成已创建回复位置的收尾，取消期间尚未开始的成员不会继续请求模型。
- 通话记录创建、逐段保存或收尾失败时，提示并结束本次通话，避免继续发言而没有可靠记录。正常服务失败仍可按原规则继续下一位；保存失败与网络失败分开处理。
- 主动挂断或恢复备份使通话失效时，沿用正常取消流程，不误报为记录保存失败。
- 补充连续三轮、刚开始就取消、转写时取消、写入时取消、发言时打断、存储失败和并发等待的离线流程测试。完整备份数据的三轮通话经序列化 / 读取后保留作者、文字、未完整播放标记和原群草稿，中断恢复后不保留运行状态。
- 使用本机 HTTP 合成服务验证两轮四次实际聊天流、四次声音请求的通话模型 / 音色与作者上下文；取消模型流或声音下载后，实际连接关闭，迟到声音不会开始播放或记录成成功发言。

861 项测试、正式构建和发布必需 lint 通过，数据库仍为 40，备份格式仍为 11。新增测试里的转写、模型回答与音频均为合成数据；HTTP 声音字节不等同于真实发音或设备播放验证。

本轮按用户要求继续电脑端开发，没有连接或操作真实手机，也未开始录音、通话或安装。真实声音、原生界面、打断时延、扬声器 / 耳机、切后台 / 来电和原生完整备份恢复仍待实机验收；当前仍是用户加两位 TA 的轮流通话试用版。

# Cleos 0.41.98 · 轮流群通话试用

- 群聊天页新增电话入口，选择两位当前在群的 TA 后明确开始。选择界面与通话页沿用玻璃实验室卡片材质；取消选择不开始录音或请求模型。
- 沿用「发语音」中的转写服务和共用声音平台，每位 TA 使用自己的已保存音色与通话模型；未单独设置音色时跟随默认。开始前检查服务、Key 与角色可用性，未配置完整时不打开话筒。
- 接通后先听用户说话，停顿后转文字，两位 TA 按顺序生成、分句合成并播放，每轮交换先后。TA 发言期间不收音，点按打断会取消这轮剩余成员并返回收音；也可静音、挂断。该版本不是可直接插话的全双工音频通话，响应速度取决于转写、聊天模型与声音服务。
- 仅使用本群记录、角色设定和本群小本本，不带入私人聊天、私人记忆或日记。模型只得到转写和其他成员的文字，不伪称听到了原声；本轮没有工具或额外接话邀请。
- 转写与实际通话文字保留在本群；播完的句子逐段保存，未完整播完的句子单独标注。其他成员尚未发出的内容在打断后丢弃，合成失败不伪装成播放成功；单个成员失败或等待超过 90 秒时可继续下一位。
- 私聊电话与群电话共用一个音频名额，释放录音和播放资源后才允许下一通；参与者在通话期间不同时进行私聊回复或其他群的回复。恢复备份、删除群或停止该群会取消通话并等待清理。重启不会自动拨号或继续请求；已有群草稿保留。

数据库仍为 40，备份格式仍为 11；通话文字使用现有群消息和回复轮次，兼容现有备份校验。原始电话音频仅用于临时转写 / 播放，不作为群录音保存。

新增 16 项测试，总计 839 项通过，正式构建和发布必需 lint 通过。覆盖身份与参与者、提示词边界、已有备份结构、音频互斥、顺序播放、取消、超时、合成 / 播放失败、长度和队列上限。实际生成的增量保存 SQL 通过内存 SQLite 验证：群 / 成员 / 轮次 / 状态不符时拒绝更新，中断恢复保留已经完成的句子与群草稿。

试用边界：尚未用真实手机跑通完整群通话，没有验证真实转写、各声音平台、扬声器回声、耳机、后台、来电切换与连续多轮的体验。编译、测试和 SQL 验证不能等同于实机语音验收。当前只支持用户加两位 TA 的轮流通话；直接插话、多人重叠发声和后台自主互聊不在本版范围。

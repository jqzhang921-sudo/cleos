# 0.41.136

书房新增每位 TA 独立的「让 TA 自己读」开关，默认关闭。

- 在「世界 → 选择 TA → 书房」开启。第一次机会约在 15 分钟后，之后每 4 小时左右给一次机会；界面显示下一次安排。实际执行由系统决定，可能受网络和省电影响而延迟。
- 与手动阅读共用每天 5 次机会。选择暂时不读也算一次有效机会；失败、取消不扣次。TA 自己选择读物、沿用原位置阅读，可以留笔记，也可以不写，不会因此发消息或发朋友圈。
- 忙于聊天 / 通话、没有可读材料或模型未配置时不调用阅读模型；错过多次安排也不会补跑一串。一次安排重复到达不会重复读取。
- 「停止阅读」结束当前片段，关闭自主阅读才取消后续机会。关闭自主阅读只停止它自己发起的后台请求，不误停手动阅读。
- 删除 TA 会清理它的安排；恢复或撤销恢复备份前停止阅读，恢复后自主阅读保持关闭，需在当前手机重新开启。

数据库升级至 47，只新增本机自主阅读安排表；书籍、位置和笔记保留。备份维持 17，不携带后台授权和待执行任务。窗外、共享相册和想读请求继续按后续计划开发。

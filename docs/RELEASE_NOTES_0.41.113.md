# 0.41.113

- 后台主动开口、补充、早晚招呼及到期提醒不再要求模型输出 SKIP；想安静时可直接结束。
- 保留旧控制格式的识别，并补充全角、零宽字符、列表、重复和代码围栏变体。
- 普通单聊、群聊和语音发送也检查纯控制词，分段返回时不先闪出 S / SK / SKI。
- 普通聊天中，用户明确要求引用或解释这个词时保留正常内容；不会删除正常句子里的 SKIP、消息编号或链接。
- 自主通话开口先检查完整文字，再交给语音；普通通话继续流式朗读。
- 被拦截的普通回复可手动重试；群聊不会因此丢掉此前已经保存的正常文字、图片或语音。

这次防护不能识别所有语义上的提示泄露或模型幻觉，也不修改、删除已有聊天记录。数据库 40、备份格式 12 不变。

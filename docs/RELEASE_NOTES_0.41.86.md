# Cleos 0.41.86

- 群聊新增查天气、读取 App 内朋友圈、搜索公开照片信息。跟随设置里的工具开关；搜索照片仅返回候选资料，群内暂未发送图片。
- 每位 TA 的回复下可打开玻璃工具记录卡片，查看本次参数、结果和中断状态，并选择部分文字复制；查询结果随群聊保存。
- 查询后由发起工具的 TA 继续回答，后面的成员可以参考本群已有结果。每位回复最多 3 轮、6 次工具调用，3 分钟总时限覆盖查询和后续回复。
- 停止整轮会取消查询；单独重试只重新处理该成员。接口明确拒绝工具时仅本轮改为文字模式，下轮仍尝试；工具参数错误和网络错误不冒充模型能力不足。
- 群内暂未开放私人记忆、日记、待办、MCP 操作、朋友圈写入、闹钟和后台约定，不把群操作写入私聊。

数据库 34 → 35 仅新增群消息工具记录字段，旧记录默认空。备份格式 5 保存工具记录，可读旧格式；旧 App 需更新后才能恢复新备份。

691 项单元测试、正式构建及发布必需的 lint 通过。本地 HTTP/SSE 测试验证了调用发现、执行身份、工具结果与下一次模型请求配对。生成的迁移及 DAO 条件已用合成 SQLite 验证；模拟器用于覆盖升级和合成记录的界面检查。尚未安装真实手机，真实模型与天气、图库网络联调、完整个人备份恢复及其他厂商机型待实测。未提交、推送或更新 GitHub Release。

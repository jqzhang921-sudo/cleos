## 2. 统一推进顺序

### A. 先整理窗外卡片与真实状态

目标：打开窗外能直接看清内容、来源和实际阅读范围，减少大块说明。

- 复用现有公开摘要、配图和已保存感想，整理“来源 / 类型 / 时间 → 原题 → 内容预览 → 实际阅读状态 → 操作”的层级。
- 来源文字、摘要笔记、曾留的看图感想分别标注。预览可展开，完整题目和原始资料保留。
- 分清获取、读过摘要、部分阅读、看过图片和留下笔记，不展示无记录的精选数、推荐理由、章数或正在整理。
- 保留批量管理、图文见闻和来源回看。每张卡的主要操作保持突出，次要操作收拢。
- 不为排版、滚动或打开页面额外调用模型生成摘要 / 感想，也不因露出图片卡就发送像素给模型。

验收重点：长中英文题目、空状态、失败与无新内容的区别、原内容及阅读进度保留、原管理操作可用。

实施记录：.168 已完成卡片层级、原文预览、真实阅读状态及摘要笔记标记的开发和本地验收，正式包准备完成，尚未安装手机。页面设置收拢与三个视图仍属于阶段 B；没有为本轮接入新来源或生成推荐理由。详见 `WORLD_OUTSIDE_CARDS_0.41.168.md`。

### B. 以融合稿整理窗外的视图和设置

目标：用同一份资料提供不同查看角度，保持入口清楚。

- **见闻**：近期公开资料与实际阅读状态，按日期 / 来源整理；保留轻量的图文漫游入口。
- **足迹**：当前真实任务与已有记录能证实的近期活动。未保存的完整任务历史不追造；若以后需要永久任务历史，单独设计数据和迁移。
- **笔记**：当前 TA 与窗外资料关联的摘要笔记、看图感想和真实问题。以记录关联回到见闻 / 随手本，不新增一份独立笔记副本。
- 窗外设置集中收拢来源与既有自主安排，长说明折叠；浏览、续查、配图 / 看图等独立许可继续分别控制。
- 同一 TA 内保留合理的标签 / 筛选 / 滚动位置；换 TA 清理属于上一位的局部选择。

验收重点：三种视图数据一致、按 TA 隔离、返回原位置、大字体和关闭动画时可操作、停止本次任务与关闭后续安排的区别。

实施记录：.169 已完成开发与本地验收，1375 项 JVM、11 项最终签名包原生检查通过。三个视图、独立滚动锚点、折叠设置及原管理入口已实现；数据库 61 / 备份 25 不变，旧资料与真实本地图片字节已核对。2026-10-31 已按既有授权同签名保留数据安装手机，回读 APK 哈希匹配，首次安装时间不变。详见 `WORLD_OUTSIDE_VIEWS_0.41.169.md`。

### C. 把之前的专题探索接进图文漫游

目标：围绕一个地方、主题或未完问题，形成能接着看的图文专题。

- 先组织当前 TA 已保存的公开资料、真实图片、感想和问题，再评估新取材方式；不要求先接全网搜索。
- 继续使用文字与图片交替、留白及小幅滚动层次，避免巨幅标题、自动无限播放和为动效制造模型请求。
- 通过专题关联既有见闻，而不是复制一套无关文章；说明哪些内容已经看过，哪些问题仍未有资料。
- 专题标题、范围与保存状态需要真实记录。涉及新数据时补齐归属、备份、删除和旧资料保留，不能只靠临时页面筛选冒充保存完成。
- 图文探索不宣称现实旅行、自拍或亲历；没有图或缺少授权时保留文字路径。

验收重点：专题与原见闻往返、真实进展、移除资料后的关联处理、恢复与 TA 切换、普通滚动和关闭动效。

实施记录：.170 已完成保存「地方 / 主题」、选择当前 TA 公开见闻、调整顺序、编辑、删除及整页图文阅读；保留原近期 24 则的随意漫游。数据库 62 与备份 26 保存分组和关联，不复制原文 / 图片 / 笔记。1383 项 JVM、16 项最终签名包原生检查通过；正式包已备好，手机在 .169 安装后断线，.170 等待新端口安装。原生备份恢复的运行诊断清理与内容保留分别记在 `WORLD_JOURNEY_TOPICS_0.41.170.md`。本阶段不新增搜索或来源抓取，后续进入 D 的固定来源核对。

### D. 页面结构稳定后再扩展取材来源

目标：增加合适的中文内容，减少手动复制粘贴。

- 首批候选为少数派、机核和 InfoQ 中文 RSS；采用前继续核对其实际响应与手机网络可达性。
- 爱范儿、36氪及其他新闻 JSON 源放在之后分别适配；微博 / 头条 / 视频榜仅作为用户可选线索，不把热度当作事实或 TA 的必选兴趣。
- 复用现有话题来源定义与解析经验，保留窗外单独的资料归属、许可与不自动发布行为。
- 同步处理来源 / URL 校验、去重、后台来源变更和备份兼容，不能仅替换链接。
- 固定来源的标题 / 摘要取回与任意关键词搜索分别表述；不因热榜可取回就声称全网查询已完成。

验收重点：来源响应范围、真实手机网络、业务错误与空响应、缓存及旧资料保留、无需额外请求就可回看已保存内容。

### E. 统一其他空间的细节，再做世界联查

- 将确认有效的文字层级、日期、来源标注、展开与反馈规则按需用于书房、随手本和相册，保留各空间适合自己的布局。
- 自由随笔、阅读笔记和相册感想沿用已有归属；窗外的笔记视图不混入私人书摘、私人照片或所有自由草稿。
- 联查世界首页 → 各空间 → 详情 → 原文 / 随手本 → 返回，以及底栏往返、重建和换 TA。
- 检查大字体、关闭动画、空内容、网络失败、取消 / 重试、删除、迁移与备份保留。
- 每版以实际证据分别记录功能完成、最终包验证和真实手机安装。当前 .167 的旧安装状态不能当作新一轮手机实测结果。

验收重点：已有四个空间可持续使用，细化没有引入资料丢失、跨 TA 显示、重复笔记或权限扩大。

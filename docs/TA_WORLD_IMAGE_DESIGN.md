## 已核对的接口与注意点

- [PageImages](https://www.mediawiki.org/wiki/Extension:PageImages)：可取得页面关联图片的名称和缩略图；`pilicense=free` 限制为自由图片。仍需回查对应图片文件的作者与许可，不能凭一个缩略图 URL 当作完整署名。
- [Imageinfo](https://www.mediawiki.org/wiki/API:Imageinfo)：`iiprop=url|extmetadata|mime|size`、`iiurlwidth` 与 `iiextmetadatafilter` 可用于取回缩略图及指定元数据。文档特别说明返回的缩略图不保证恰好等于请求宽度，因此实现必须验证实际响应字节数和解码尺寸，而不能只信请求参数。
- [Commons 重用说明](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia)：每个文件有自己的许可，应保留创作者、来源页和许可链接；上传者不一定是作者。产品应显示实际取得的元数据，不对全部文件作笼统的版权保证。

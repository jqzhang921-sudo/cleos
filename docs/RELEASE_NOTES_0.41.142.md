# 0.41.142 · 沿着问题继续查阅

世界首页「还想知道」、随手本中带疑问的笔记，以及「窗外」新增「继续查阅」入口。可以修改检索词，查询中文维基百科，最多保存三条百科导言摘要；保留最初检索词、来源链接与获取时间。检索不调用模型，不把获取结果写成已经读过或问题已解决。

取得结果后，可让 TA 只从这批结果中选择阅读或暂停，沿用角色设定与少量近期公开笔记。阅读共用书房每日五次机会，失败或停止退回；保存的仍是可读笔记与逐字核对的摘录，不是普通输出或内部思考。重复检索复用已有摘要，保留最初来源与阅读位置；本次检索词单独提供给模型，不改写旧记录。

这是手动继续查阅的首步。点击查找仅向中文维基百科发送输入框中的检索词，不发送私聊、用户记忆或整本笔记；模型阅读在点击「让 TA 看看」后开始，实际发送范围在页面说明。未获取图片、完整条目或全网搜索，没有自动发聊天或朋友圈。现有窗外后台开关仍只获取用户选定的订阅源，不自动把问题发送给百科服务。

复用已有获取任务的取消、跨 TA 隔离与恢复 / 删除前排空规则。请求使用固定 HTTPS 接口，不携带模型密钥或 Cookie、不跟随重定向；限制响应大小、JSON 深度、结果条数、文本长度和合法来源。服务错误、无结果和取消分别呈现，已有见闻保持。

数据库 50 → 51 只新增文章的 `searchQuery` 空字符串默认字段。备份格式升级到 20，包含检索词；旧备份仍可读取，新备份需新版手机 App，电脑版 0.13 暂不能导入。后台授权仍不进入备份。

接口核对：[MediaWiki Search](https://www.mediawiki.org/wiki/API:Search)、[TextExtracts](https://www.mediawiki.org/wiki/Extension:TextExtracts)。百科内容注明 CC BY-SA 4.0 等条款及原始页面作者 / 修订记录入口。

后续：由 TA 自主选择续查主题与对应授权 / 预算，更多合适来源，以及用户确认的图文旅行册。图文方向保留整体壁纸与玻璃风格，以克制字号、图片留白和轻微滚动层次呈现；本版尚未开放图片检索和共享相册。

验收：1188 项单元测试、12 项原生场景、7 项界面检查通过。独立模拟器实际获取中文维基百科导言，模型阅读仅使用本地合成 HTTP / SSE；未调用用户的真实模型。迁移与界面操作后，原测试库的 44 条读物与见闻、8 条笔记、1 条想读记录逐字段核对不变。证据保存在工作区 `outputs/Cleos-0.41.142-topic-lookup/`。

# 模型与 MCP 的 HTTP 兼容边界

HTTP 不提供传输加密。界面确认只表达用户愿意向该来源发送明文，不证明服务可信，也不防止网络中间人读取或修改内容。公网应优先使用 HTTPS。

## 放行方式

Android 对未知的用户自填主机不能通过固定 XML 逐个预先列举，因此正式包声明 `usesCleartextTraffic=true`。限制由应用共用的 `EndpointTransport.clientBuilder()` 执行：普通请求没有授权标签，HTTP 在建立连接前被拒绝；模型及 MCP 通过各自的 `prepare` 回调读取最新许可，再获得只适用于当前协议、主机和端口的内部标签。

应用拦截器检查请求起点，网络拦截器检查实际发送地址。对带标签的接口，收到重定向响应时先核对 Location，跨来源时在打开目标连接前停止，并在每次实际发送前再次核对。HTTPS/HTTP 之间的自动跳转也关闭。同源相对路径跳转可继续。没有自定义宽松证书信任或主机名验证器；HTTPS 仍使用 OkHttp / Android 默认校验。

当前联网客户端均从此共用实例派生。Coil 只处理本地文件，未引入网络模块；没有额外的 WebView、URL 连接、原始套接字下载或 DownloadManager 网络路径。后续增加客户端或网络图片加载器时必须继续接入同样的默认拒绝检查，不能仅依赖 Android 的平台标记。

## 许可范围与存储

- 模型许可键为 `model|来源`，同源的聊天、通话模型及所有 TA 共用。MCP 为 `mcp:服务编号|来源`，不借用模型或其他服务的许可。
- 来源包含协议、规范化主机及实际端口；路径、查询、Token 和 Key 不进入许可键。许可覆盖该来源的所有路径。含 URL 用户名 / 密码或片段的接口地址被拒绝。
- 许可保存在 SecretStore 的加密、设备绑定数据中，不进入 Cleos 备份；Android 10/11 的 full-backup-content 与 Android 12+ 的 data-extraction-rules 都排除这份存储。新设备重新确认。原机恢复普通备份不会替用户清除已经存在的本机许可。
- 默认无许可；确认弹窗前不授权。最多保留 128 项，损坏存储按无许可处理，编辑通过互斥锁合并。删除 MCP 服务清理该服务的许可。
- 每次模型测试、模型列表、流请求及兼容重试，以及每条 MCP JSON-RPC 请求都重新检查。MCP 工具缓存不能绕过关闭后的发送检查。关闭阻止新发起的请求，不能收回已发送的数据，也不自动取消正在进行中的请求及其同源跳转。

## 范围

仅开放聊天 / 通话模型与 MCP；转写、声音生成、图库、资讯、天气及更新检查没有 HTTP 许可入口。外部浏览器里用户主动打开的链接由浏览器负责，不是 Cleos 的携带凭据请求。

HTTP 上的 MCP 工具描述、只读标记、参数与结果也可能被篡改。现有工具确认机制不等于传输可信；不要将这个兼容入口描述为安全的远程授权方案。

自动化验证使用实际共享网络工厂、ChatClient、McpClient 和本机合成服务器，覆盖未授权零请求、撤销、服务隔离、同源跳转、跨来源零目标连接及原有 HTTPS 构造。Android 明文放行与弹窗另做手机检查。没有声称渗透测试、所有 Android 厂商或所有真实供应商都已覆盖。

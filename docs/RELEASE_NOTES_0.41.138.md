# 0.41.138 · 阅读结果保存检查

修复一种会让有效阅读结果被误丢弃的问题：阅读期间，如果后台只更新了 TA 的“上次写信时间”，原先对整条角色资料的比较也会把本轮阅读当作过期，退回次数并显示“没有得到可确认的阅读结果”。

现在只检查本次阅读使用的角色身份、名字、设定和模型配置；写信时间、头像、聊天偏好等无关变化不会丢弃有效阅读或想读请求。原文、阅读位置、任务权限、密钥或实际角色 / 模型发生变化时，旧结果仍会被拒绝；手动停止也继续阻止晚到结果写入。

聊天 / 通话占用、配置变化、读物变化和保存异常会显示各自对应的原因。精简诊断增加保存阶段与异常类别，不记录原文、模型输出、Key 或异常原始消息。

数据库维持 48，备份维持 18，书籍、笔记、想读清单和本机自主阅读开关不迁移。

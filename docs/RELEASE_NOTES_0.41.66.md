# 0.41.66：局部复制与可点击链接

- 长按聊天消息，新增「选择文字」。在玻璃卡片中长按、拖动选区，使用系统菜单复制选中的片段；原来的「复制」仍复制整条消息。
- 选择文字卡片采用玻璃实验室的「卡片」材质，字号跟随聊天设置。支持普通文字、语音转写及转发消息中的可复制文字。
- 聊天消息、展开的语音转写及工具详情中的 HTTP/HTTPS 地址可直接点击打开，支持 `[查看订单](网址)` 形式的链接。
- 链接保留查询参数和签名，不包含句尾标点；无法打开时给出提示。原始消息及整条复制内容不变，不访问链接预览，也不会自动提交订单。
- 流式回复完成后才启用聊天链接，避免打开尚未生成完整的地址。
- 不涉及模型配置、聊天记录或数据库迁移。

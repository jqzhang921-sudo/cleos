# 0.41.65：修复 DeepSeek 工具误判

- 识别 `deepseek-flash`：关闭深度思考时明确发送 `thinking.type=disabled`。
- DeepSeek 开启思考且使用工具时保留此前轮次的 reasoning；普通回复和拆分的消息气泡也保存并回传所需字段。已有历史缺失的字段不会伪造思考内容。
- 普通 HTTP 400 / 404 / 422 不再被当成不支持工具，也不会因此禁用内置工具和 MCP。只有服务端明确拒绝相应功能时才允许降级。
- 关闭思考参数的自动重试同样检查明确的拒绝原因，不因普通请求错误记住「不支持关闭思考」。
- `CleosTools` 日志记录模型、思考开关、工具数量和名称、reasoning 字段是否存在、HTTP 状态及脱敏错误类别。不会记录 Key、地址、聊天正文、思考正文、工具参数或原始错误正文；未知错误字段会隐去。
- 首次故障的 HTTP 响应未留存，历史触发原因仍需新请求验证。此版本修正已证实的兼容性缺口和误判机制，不宣称恢复了旧的原始响应。
- 不涉及数据库迁移、模型配置或聊天记录清理。

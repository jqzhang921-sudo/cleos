# Cleos 0.41.75

- 已配置的 MCP 工具返回标准内嵌图片时，保存到本机并在聊天中显示玻璃图片卡片，可点击查看；图片注明服务来源，不会被折叠进工具记录。
- 图片跟随对应工具消息备份、恢复和删除。旧聊天图片无需迁移。
- 支持 PNG、JPEG、WebP（静态预览）；单张最多 2 MiB，每次工具最多 3 张、每轮回复最多 6 张，长边缩到最多 1536 像素。超限、损坏或保存失败会提示未能显示。
- 仅供模型参考的图片和失败工具结果不自动展示；保留现有 MCP 权限确认。原始图片数据不写入聊天文本或工具诊断。
- 只返回 URL 的工具仍显示链接。本版尚未接入新的搜图或 AI 生成服务，也不会因收到链接自动下载图片；是否能找图、生成图片取决于用户已配置的 MCP 服务。

验证：561 项单元测试通过（0 失败、0 错误、0 跳过），release 编译、vital lint、修改格式检查和签名校验通过。已安装到此前授权的调试手机，确认版本 0.41.75（152）并成功启动，原安装时间保留。

图片结果通过本机模拟 MCP 请求与存储回调测试；实际外部图片服务和手机上的图片卡片展示尚未验证，未进行付费或外部联网调用。

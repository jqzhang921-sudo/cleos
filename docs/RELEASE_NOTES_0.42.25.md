# Cleos 0.42.25

这次更新了 Android 版的日历、聊天、语音通话和玻璃界面。

- **日历和待办**。待办日历可以下拉切换一周、月历和带日程的月历，拉到尽头会回弹。日记日历保留周视图和月视图。
- **聊天**。重新生成回复或编辑自己的上一条消息，可以在原对话里切换版本。相册留言旁的「回复」会打开对应 TA 的私聊，发出后可在引用卡片里查看完整留言。群聊调整了字号、名字和气泡的对齐。
- **数据导入**。「数据与备份」新增 DeepSeek 聊天导入，通用导入支持 Chatbox 备份 ZIP。
- **语音通话**。字幕以对话形式显示，可以轻点屏幕切换显示，单人通话支持字幕翻译。通话里的打字输入框和静音、挂断按钮也做了调整。
- **界面**。调整浮动导航的大小、选中效果和文字标签。统一更多玻璃胶囊的材质，并改进菜单、页签和按下反馈。
- **记忆**。带有来源的记忆可以跳回原聊天，支持适用日期、去重、整理建议和撤销。记忆页右上角与整理页的切换样式也做了调整。

## 安装

在 Cleos 里点「去蓝奏云看新版」，下载 `Cleos-0.42.25.apk`（版本代码 305）。直接覆盖安装即可保留现有数据。

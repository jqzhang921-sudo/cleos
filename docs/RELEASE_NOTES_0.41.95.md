# Cleos 0.41.95

- 群成员可以自行选择发一条短语音，适合话题时发，平常仍可打字。每位每轮最多一条、300 字；沿用现有共用声音服务与音色，需要配置「TA 的声音」并开启「能做的事」里的发语音。
- 语音保留实际发言者，可播放并展开声音对应的文字，后续补充文字独立显示；其他成员读取的是文字，不假装听到了语调或音色。
- 合成失败或等待超过 45 秒时保留原话为文字。只有本群实际保存成功才确认发出；停止取消未完成合成并清理未发布文件，已提交的语音保留，单独重试只替换失败成员的当前尝试。
- 语音随群消息保存、删除和备份；缺失文件仍保留说过的文字。增加不含 Key、正文和原始响应的降级阶段诊断。
- 修正语音气泡和工具记录改变高度后，最新消息可能被输入框遮住的问题。用户语音输入框保持现有样式。
- 修正流式回复正常结束后仍取消已完成连接的清理行为；正在执行的请求仍能停止和超时取消。

数据库保持版本 38，无新增表或迁移；使用现有音频字段，分别保存实际说出的文字与后续补充文字。备份格式升级为 9，继续读取旧备份，新备份需更新 App 后恢复。

792 项单元测试、正式构建和发布必需 lint 通过。合成数据的语音保存、停止、逐成员重试、播放和备份恢复已验证；合成音频为测试音，真实声音服务与用户录音转写仍需实机验收。网络压力测试仍偶发连接提前结束，本版会保留原话为文字，未宣称消除所有接口问题。

本版没有接入多人实时通话、每位 TA 独立音色或自主互聊。

# Cleos 0.41.78

- 「能做的事 → 找照片」增加照片来源选择：WordPress 照片库与 Openverse。已有用户保留 Openverse，可手动选择 WordPress 并使用「测试图库」。两者都无需填写 Key。
- WordPress 搜索优先精确标签；没有对应标签时按完整词匹配照片描述，避免 cat 命中 delicate 等无关结果。支持猫、狗、沙滩、美食等少量中文常用词，其他查询优先用简短英文关键词。
- 优先下载清晰预览；加载失败时在整体 20 秒预算内尝试小尺寸预览，并在图片卡片、工具回执和图库测试中说明。小图说明及作者、来源、CC0 许可随聊天备份保留。
- 图库选择进入备份；切换图库后，之前搜到的照片仍从原图库下载，沿用当前 TA、当前对话、10 分钟有效期和每轮图片数量限制。
- 图片下载限定为经过校验的 WordPress 静态预览域名与路径，不跟随重定向、不下载原图，也不修改手机代理。

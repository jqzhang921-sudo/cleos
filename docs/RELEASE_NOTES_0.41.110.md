- 群聊接入「能做的事」中已开启的系统日历查询、闹钟和计时器；日历只读，其他 App 的内部课表需要先同步到系统日历。
- 工具定义随每次请求提供，执行前重新检查开关；每位 TA 的历史措辞不代表其他成员本次实际具有或缺少相同工具。
- 同一轮相同钟点/重复日期的闹钟或相同时长的计时器避免重复创建；上次执行状态不明确时先提示核对手机时钟，不假报成功。
- 群聊提示每位 TA 根据实际附图独立核对日期、星期和课程所在列，不把其他成员的说法当作已核实的事实。识图和模型回答仍可能出错。

- 备份格式升级为 12，保存新增群工具记录，继续读取旧备份；新备份请使用新版 App 恢复。数据库仍为 40。

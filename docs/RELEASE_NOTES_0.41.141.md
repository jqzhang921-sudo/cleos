# 0.41.141 · 窗外自主浏览

「世界 → 窗外」新增每位 TA 独立的「让 TA 自己看看」开关，默认关闭。开启后约 15 分钟给首次机会，此后约每 4 小时一次；只从当前选定的公开来源获取摘要，再由 TA 自选阅读或暂停，可留下随手本笔记。更换来源会取消旧后台执行并重新安排首次机会。

与书房共用每日五次阅读机会，不自动发聊天消息或朋友圈。缺少模型配置、忙于聊天 / 通话、额度耗尽时不获取订阅或请求模型；获取失败保留缓存，不扣阅读额度。成功获取与实际阅读分别记录，仍不访问网页全文或图片。

书房和窗外的后台授权分别保存；关闭其中一个不会取消另一个，也不误停用户手动开始的获取 / 阅读。停止当前刷新或阅读仅结束这一次，关闭开关才取消未来机会。后台执行使用来源、TA 创建时间、安排版本和到期时间验证权限；关闭、更换来源、恢复备份或删除角色会阻止旧结果落库。

采用按网络约束的一次性 WorkManager 安排，先存下次机会再开始网络；重复唤醒只核对当前安排，不连续补跑积压任务。系统或省电策略可能延后执行，不承诺准确到点或强制结束 App 后仍可唤醒。实现参考 [Android WorkManager 管理与取消](https://developer.android.com/develop/background-work/background-tasks/persistent/how-to/manage-work)。

数据库 49 → 50 仅增加本机窗外授权表；书籍、摘要、笔记、想读请求、阅读位置及原书房开关不迁移。备份维持 19，既不导出也不恢复两类后台授权，恢复后需要重新开启。Worker 类名与构造保留，支持进程重启后按已存安排由系统创建。

后续继续做围绕兴趣和未完问题的定向续查；共享相册尚未开放。

验收：1177 项单元测试、19 项原生调度与取消场景、7 项界面检查通过；独立模拟器验证了系统重建进程后执行、切换来源、关闭授权、手动操作互不干扰及备份恢复。迁移后逐字段核对原有 16 条读物与见闻、3 条笔记、1 条想读记录未变。真实模型未参与测试，不能据此判断模型实际阅读质量。

正式签名 Release 和 lint 检查通过；独立模拟器完成从 0.41.140 覆盖升级，验证开关默认关闭、开启后重启保留、切换来源和关闭，以及旧 PDF / 想读记录 / 见闻来源保留。真实手机当前离线，本轮尚未安装；手机厂商省电策略与长期后台表现仍需实际使用观察。完整证据位于工作区 `outputs/Cleos-0.41.141-outside-background/`。

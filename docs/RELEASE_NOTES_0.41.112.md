# Cleos 0.41.112

- 思考期间网络中断且尚未收到正文时，错误提示说明“尚未生成回复”，并保留原始错误原因；已收到部分正文的情况继续展示原有错误。
- 请求结束、保存结果尚未显示的交接期间，思考面板不再继续显示为“进行中”或生成新的等待提示；隐藏思考时也不留下等待气泡。
- 中断请求的思考仍放在可折叠的回复过程面板，收起时显示小警告图标，展开后注明“回复已中断”。不显示思考时长，不改变工具图标连接条。
- 增加思考中途断线的解析、正文分离和显示交接回归验证。

这修正中断提示与收尾状态，不等于已查明截图用户的网络断连原因，也不证明上游从未把无标记推理放入正文。仍保留原有手动重试行为；未增加聊天请求自动重试、正文关键词过滤或旧聊天记录迁移。数据库版本 40、备份格式 12 不变。

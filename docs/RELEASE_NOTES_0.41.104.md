# Cleos 0.41.104 · 后台开口内容隔离

- 自主找话题、稍后想起、例行问候和自然补充所走的后台唤醒流程，统一检查普通文字回复、带工具调用的文字、send_message 与 send_voice。SKIP 控制结果及其括号、Markdown、大小写、说明后缀和重复形式不会发成聊天消息；检查发生在语音合成之前。
- 拦截已知后台提示的原文片段复述，兼容换行和标点变化。这里只识别 App 已知的后台模板，不以用户姓名、记忆或提醒正文作匹配规则，也不能保证识别所有改写后的提示泄露。
- 后台决策思考不再作为聊天思考存储或展示；已有后台记录的思考在展示层隐藏。当前轮工具续问所需的 reasoning 仍留在请求内存中，正常聊天的思考功能保留。
- 组装后续聊天请求时排除旧后台 SKIP 和已知后台提示复述；有效工具调用和对应结果仍按协议配对。普通聊天讨论 SKIP、正常编号和链接不受这项后台过滤影响。
- 普通聊天不再包含后台 SKIP 协议说明；补充内部编号只用于定位的规则，避免把消息编号当成对方名字、回复前缀或签名。没有用正则删除全部 #数字，也不保证模型永远遵守文案约束。

没有自动删除旧异常消息、重写既有摘要或改动群聊界面。数据库仍为 40，备份格式仍为 11。

验证：133 套件、932 项单元测试通过，无失败、错误或跳过；正式构建、发布必需 lint 和同签名 APK 校验通过。新增覆盖后台控制结果、提示复述、分片 SSE 文字 / 思考 / 工具参数、正常文字不误删、历史上下文配对及后台思考展示。未连接真实模型复现这次间歇问题，也未安装或在手机上验收本包。

版本 0.41.104 / versionCode 181。新 APK 放桌面，旧 .103 归档至「旧版本」。本轮未暂存、提交、推送或发布 Release。

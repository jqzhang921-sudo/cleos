# Cleos 0.41.128 · 群聊里的共同记忆

- 群聊成员中新增每位 TA 的「记忆共享」。默认关闭；可以搜索、展开查看细节，逐条选择允许这位 TA 在这个群参考的记忆，最多 20 条，保存后生效。取消不会改变授权。
- 文字群聊和群语音通话都只向发言 TA 自己的模型提供获准记忆，不读取其他 TA 的私人记忆、私聊、日记或设定库，也不自动把群聊经历写回私人记忆。已经在群里公开的话仍属于本群聊天历史。
- 选择覆盖整条记忆及其细节；每次按当前话题和长度选取完整主题。记忆修改或删除后不再读取旧授权，新记忆也不会自动加入，需要查看当前内容后重新勾选。关闭全局记忆能力时，本群同样不读取。
- 回复或通话进行中先停止，再调整共享。关闭后停止后续读取，已经说进群里的消息不会撤回；新加入的群成员仍能看到本群已有历史。
- 离群清空该 TA 的本群授权，重新加入需再选择。共享授权不随 Cleos 的应用内备份、撤销恢复或扫码导入自动恢复；原始私人记忆仍正常包含在完整备份中。此处不改变 Android 系统自身的整应用备份规则。
- 数据库 43 → 44 只为群成员新增两个带默认值的字段，已有群聊默认不共享，不删除旧消息或原记忆。Cleos 备份格式保持 15，电脑版代码和功能没有变化。

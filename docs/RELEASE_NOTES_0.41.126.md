# Cleos 0.41.126

- 来电通知统一显示「语音来电 · TA 名字」、电话图标和接听/拒绝入口，避免折叠后与普通消息混淆；通知作为等待处理的来电保留，接听、拒绝或超时会移除。
- 来电等候时间由 45 秒延长为 60 秒。此时间是可接听窗口，不保证所有系统横幅都停留相同时长。
- 「说话方式 → TA 主动来电」增加「持续横幅与锁屏来电页」，默认关闭、所有 TA 共用。开启后请求系统持续来电横幅；锁屏时可出现来电页，部分手机需另行允许全屏通知。
- 锁屏来电页不显示私人来电理由，不开麦、不自动接听；点击接听需先解锁，再进入原有接听流程。过期、已处理和已删除的邀请无法从旧提醒重新接通。

没有新增数据库字段或备份格式；持续提醒开关是本机提示方式，不写入应用内导出备份。

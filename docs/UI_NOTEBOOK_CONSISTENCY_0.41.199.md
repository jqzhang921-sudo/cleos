# 搜索与筛选一致性 · 0.41.199

随手本和我的书签复用聊天页的 GlassSearchField：玻璃胶囊、相同字号和图标间距，保留各自提示词和清空辅助标签。

随手本分类、书架分类、整理读物分类和原文显示切换统一 WorldFilterChip，采用记录页筛选比例：44dp 最小可见高度、16dp 水平留白、9dp 垂直留白、全圆角和明确的单选语义。大字号允许自然增高。卡片保留原有 24dp 圆角和单列列表，正文继续上下阅读。

本轮不修改数据库、原文、阅读进度或分卷规则。现有 WorldBookVolumes 只把同一 TA 下同书名、作者、源 EPUB 文件名且完整无重复的 Part X of Y 集合投影成一本；PDF Vol_1/Vol_2 不符合该规则，暂无手动归组入口。不能把「整理读物」误说成合并分卷（它仅修改分类及杂志刊名/期号），也不能把随手本连载整理混用到导入书架。

后续可单独设计手动分卷归组：用户确认所选卷和顺序，仅新增归组关系，原始文章、每卷阅读位置、笔记和书签身份保持。此次不自动按相似标题合并。

验收证据位于会话 outputs/Cleos-notebook-consistency；以最终 LOCAL-ACCEPTANCE.json 和 PHONE-INSTALL-RESULTS.json 为准。

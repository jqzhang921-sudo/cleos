# 0.41.133

书房可以从手机文件中添加 PDF、EPUB、TXT 和 Markdown。先预览，再确认书名和来源放入书架，粘贴文章保留为补充入口。

PDF 提取可读文字并保留页码标记，EPUB 按章节阅读顺序导入；支持继续上次的位置、随手本摘录和回到原文。导入不会调用模型，开始阅读时才发送本次片段。

每份最多 20 MB、50 万个字符，超限明确提示，不静默截断。暂不支持扫描件 OCR、加密 EPUB、PDF 密码输入、原图片 / 排版和批注。保存的是提取文字，原文件请自行保留。

手机备份升级为 17，包含提取后的书籍文字、阅读位置与笔记，旧手机备份仍可恢复；电脑版 0.13 暂不支持新格式。

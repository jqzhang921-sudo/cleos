# 0.41.137 · 书架之外，想读的书

书房新增和书架平级的「想读的」页签。TA 可以在阅读机会中提出一本书架上没有的书，留下一句想读的理由；也可以挑现有读物或保持安静。空书架也能给一次书房时间。

你可以以后再说、忽略、移回待添加，或添加自己的文件，再确认关联书架中的对应读物。请求不算读过，也不会自动购买、下载或发送聊天消息。每位 TA 每 24 小时最多新增一条，同名请求去重；待添加 / 暂缓最多 10 条、历史最多 100 条。沿用每天五次书房机会，失败或停止会退回。

模型提出的书目会标明未核实。点「核对书目」可选择向 Open Library 查询书名 / 作者，再由你选中对应书目；不会发送角色设定、聊天、原文或密钥。没有候选或网络失败会保留未核实状态。书目查询不提供正文。

本次数据库升级保留原书、位置和已开启的自主阅读安排。手机备份升级至格式 18，包含想读清单和关联；旧备份仍可读取。电脑版 0.13 暂不支持新格式。恢复备份后自主阅读仍需重新开启。

验证：1157 项单元测试全部通过，lint 无错误；独立模拟器完成 15 项原生检查及正式包页面点按检查，公开书目查询在 Android 上验证成功。未使用实际模型进行测试。

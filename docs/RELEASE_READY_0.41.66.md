# Cleos 0.41.66：阶段更新与发布检查

检查日期：2026-10-09。安装包版本 0.41.66，versionCode 143。

## 这次可以分享的更新

相对远端的 0.41.38，本次累计更新包含：

- 朋友圈与资讯话题：共享动态页、顶满封面与磨砂玻璃内容区、弹性下拉菜单。
- 图文动态：最多 9 张照片，支持点赞、评论、回复具体的人及删除；修复点赞时跳动和帖子菜单裁切。
- 转发到聊天：玻璃卡片、选择 TA、保留原帖快照与照片副本；可附上自己的话再发送。
- 邀请 TA 看看动态或评论，明确作者和回复对象，避免对自己的正文或评论再回应。
- 主动逛朋友圈：各 TA 独立开启，默认关闭；频率、免打扰、每日次数和自动发帖上限。
- 生活资讯：猫猫宠物、旅行风景、美食厨房、科技数码、科学太空及自填 RSS / Atom；TA 按兴趣选题，也可以保持安静。
- 保存并复用模型配置；编辑过程为草稿，明确保存或使用配置后才应用，避免误触改变模型。
- 聊天与工具记录可多选删除，一键回到最新消息；「还有句话」与「想找你聊」独立设置，TA 可规划下一次找话题时间。
- 修复 DeepSeek 普通接口错误被误判成不支持工具的问题，补齐 `deepseek-flash` 思考开关和历史 reasoning 兼容。
- 长按消息选择部分文字复制，聊天及工具详情的网页链接可直接点击。

详细记录见 [朋友圈计划](MOMENTS_PLAN.md)、[工具修复](RELEASE_NOTES_0.41.65.md) 和 [复制与链接](RELEASE_NOTES_0.41.66.md)。

## 留到后续的内容

- 共同存钱罐 / 钱包、共同目标、月度小票仍在设计计划中，当前版本没有实现。
- 局部复制选区、长按菜单和链接点击已编译并覆盖安装，完整真机交互仍需使用反馈；不能把安装成功当成交互验收通过。
- 朋友圈自动阅读及发帖的真实模型表达、长时间后台唤醒没有完成现场验收。后台执行受手机省电影响；这些新开关默认关闭。
- 资讯来源的数量与可用性会变化，现有来源读取结果不代表所有用户网络都可用。

本次检查没有发现应用中的 TODO / FIXME 或未实现占位，也没有把钱包半成品接入界面。建议作为阶段更新供现有用户试用，后续继续收集朋友圈和新聊天交互的反馈。

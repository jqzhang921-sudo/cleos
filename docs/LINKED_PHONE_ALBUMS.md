# 关联手机图集 · 0.42.22

入口：世界 → 选择 TA → 相册 → 关联手机图集。每位 TA 第一版关联一个本地图集，重新关联可替换；解除不删除手机原照片或已有本地副本、感想。

## 范围与权限

- Android 29–32 请求照片存储读取；33+ 请求图片读取，34+ 支持系统的部分照片授权。没有视频、照片位置或写入权限。
- 系统授权和 TA 范围分别管理。系统权限可能覆盖多图集，Cleos 按指定的 volume + bucket 过滤。
- 默认仅关联这次可访问照片的 metadata identity 快照。只有完整图片权限下，用户显式开启“包含以后新增的照片”才纳入之后的新图；部分授权无法开启。
- 关联不会自动开启自主翻看。沿用相册现有的独立开关、模型配置、机会与后台安排。
- 候选只包含图集名、日期和临时编号。TA 选中后重新验证，再复制、缩至 960px、重新编码去除原始 EXIF，通过现有看图流程发送一张。没有批量上传，也不自动发聊天或动态。
- 同 TA、同像素已经确认看过的照片不会自动重复发送。50 张本地副本上限保留，满后整理，不覆盖已有照片。单图集快照最多一万张，超出要求缩小授权范围。

## 撤销与恢复

每次自动访问核对角色创建时间、关联 revision、系统权限和原照片 metadata identity。撤销/移动/删除/修改后的来源不能继续自动读取；主动手动重看本地副本仍沿用单次确认。

权限类别发生变化时持久暂停关联，需要重新关联，重新授予系统权限不会自行恢复旧授权。系统在两个检查之间撤回又授予、或没有提供 metadata 变化的编辑，不能被客户端追溯检测。

关联、初始照片键和导入来源保存在 noBackupFilesDir 的 AtomicFile，仅在本机。数据库 68→69 为相册副本添加 fromGallery=false 默认字段；备份格式 33 保留此标记但不导出关联。恢复前清除设备关联，缺失/损坏关联时来源副本自动访问一律拒绝。旧版本手动选图数据不变。电脑版解析器同步接受格式 33，既有桌面可执行包没有重发。

## 验证边界

使用自有 Android 模拟器、合成图片、隔离 Room 和拦截模型请求测试。不扫描用户手机相册、不调用用户模型；真机覆盖安装不会替用户授权照片。厂商私密相册和仅存在云端的图集不保证由 MediaStore 提供。

# 0.41.154：书房在线文库

## 行为

- 「世界 → 书房 → 添加读物 → 从在线文库找读物」提供中文维基文库的手动检索，每次至多 5 个主名字空间页面。搜索、取回、预览与确认加入分开；键盘可直接搜索。可随时改用现有 PDF / EPUB / TXT 导入。
- 只取所选页面的固定修订文字，可能是文章、章节或目录，不自动合并整本书、跟随章节链接、获取图片或增加后台下载任务。保留正文内作者 / 版权文字、固定版本来源和 CC BY-SA 4.0 等许可说明。原文页可打开固定来源，恢复备份后仍可回查。
- 检索只发送用户填写的关键词。独立 HTTPS 客户端不携带模型 Key、聊天、用户记忆或 Cookie，不跟随重定向；只请求固定来源 API。响应有字节、结构深度和条数上限，页面编号、修订与标题必须与选择一致；超限或失败不截断保存，不把失败当成空结果。
- 预览不保存，不调用模型，不消耗阅读额度。明确确认后才按 TA 保存为已有的书房读物；后续阅读沿用原流程。相同文字重复添加保留原读物和位置，另一位 TA 单独保存。大正文留在内存，不写入页面恢复 Bundle；退出取消请求，重建页面不自动重发。
- 在线文库目的地与至多 100 字的检索草稿单独保存在可恢复导航状态中；放大字体后仍留在文库并保留检索词，切换 TA 清空草稿，取回的结果和正文不自动恢复或重发。预览的来源卡与正文分开，切入预览回到开头；键盘弹出时不再预留底栏渐隐，避免遮住正在输入的文字。
- 资料恢复期间拒绝尚未提交的读物写入；过期 TA 身份也不能保存。没有新权限、后台安排或数据库表；数据库 59、备份 24 不变。

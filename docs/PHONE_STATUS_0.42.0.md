# 手机状态：0.42.0 发布前补充

范围：设置 → 能做的事 → 手机状态。两个独立开关默认关闭，所有 TA 共用，仅私聊；群聊工具白名单不包含它们。打开前明确说明发往 TA 配置的模型接口并存入聊天工具记录，关闭不撤回已发出的记录。

- 电量：get_phone_battery，一次性读取电池剩余百分比和充电状态，带查询时间。无效值返回不可用，不能写成 0%。
- 今日使用时长：get_phone_usage。经用户确认分享后跳转系统使用情况访问页面，只有确实授予权限才开启。已开启后撤权会显示提示并拒绝读取。
- 统计口径是今天本地午夜起「亮屏且解锁」区间的并集，标为估算；查询前一天的开关屏/锁屏状态只为衔接跨午夜的区间。缺失状态仅返回已确认部分或暂无统计，不谎称零分钟。按当地日期计算，兼容 23/25 小时的夏令时日。设备重启不跨越关机空档计算。
- 不读取、存储或上传应用名称、包名、页面、屏幕截图、聊天内容、原始事件；不申请全部应用列表权限或无障碍权限。系统 queryEvents 返回对象后只提取屏幕/锁屏事件类型和时间，扫描有上限并支持取消。
- 私聊与已有自主唤醒可以按需调用；没有新增电量广播接收器、轮询服务或后台唤醒任务，不改变主动消息频率。本机预览不调用模型。
- ToolBox 检查当次开关及正数私聊/TA 身份；GuardedPhoneStatus 在读前和返回前重新检查当前开关；系统使用权限同样读前、返回前复核。授权与读取失败不自动引导模型绕过授权。

数据库仍为 66，备份格式仍为 29；工具开关沿用按名字编码。旧设置缺少这两个名字时默认关闭。统计原始事件不落盘。

Android 依据：
- https://developer.android.com/training/monitoring-device-state/battery-monitoring
- https://developer.android.com/reference/android/app/usage/UsageStatsManager
- https://developer.android.com/reference/android/app/usage/UsageEvents.Event

验收：1510 项 JVM 测试及本轮 13 项原生检查通过。最终签名包完成默认关闭、确认/取消、系统授权返回、撤权提示、Android 电量服务读数、本机使用时长预览、离线合成模型工具回合，以及关闭开关后的恶意工具请求拦截。测试环境原始资料、设置、图片、系统使用权限模式和电池模拟已恢复，专用模拟器及本地服务已关闭。证据在会话 outputs/Cleos-0.42.0-phone-status；真机更新单独记录，用户的使用情况权限由本人选择，不自动开启。

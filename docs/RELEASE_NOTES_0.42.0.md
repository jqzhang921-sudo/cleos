# Cleos 0.42.0 更新说明

**更新范围：0.41.111 → 0.42.0。** 这次把近期陆续完善的功能整理成一次正式更新。

## 世界：让 TA 有自己的阅读与创作空间

- 新增书房、窗外、随手本和相册，沿用壁纸与玻璃风格。
- 书房支持添加 PDF、EPUB、TXT、Markdown 等读物，记录阅读位置、笔记和书签，也可开启自主阅读。完整且可识别的 EPUB 分卷可合在一本下展示。
- 窗外支持公开摘要、专题与图文见闻，补充少数派、机核等来源。在线文库和百科仍取决于网络环境；Bing 是网页搜索入口。
- 随手本支持随笔、草稿、虚构故事与连载整理，采用卡片列表，打开后上下阅读。
- 书架近况、已保存的想读理由和阅读进度可以回到聊天；续读带上本书旧笔记、已读末尾片段和相关读书偏好。没有笔记也能保留读过的进度。

## 记录与专注

- 日记和待办集中到「记录」，支持列表与月历切换，共用日期选择，改善切换过渡和日期条反馈。
- 新增专注计时、休息与 TA 陪伴，完善结束提醒及前后台衔接。

## 聊天、群聊与通话

- 增加消息翻译，译文展示更紧凑；支持消息发送偏好，兼顾分条聊天与完整长消息。
- 每位 TA 可以使用不同的用户头像。语音条、旁白、搜索框、底栏图标和用量/缓存详情的展示进一步统一。
- 群聊可逐条授权 TA 在当前群参考哪些记忆，默认关闭，不自动分享私人资料。
- 完善群语音的收起、后台、挂断和分阶段错误提示，修正较早群聊回复重试时的上下文衔接。
- 增加可选择开启的 TA 主动来电，完善接听开场、来电通知与频率设置。
- 补充迁移到电脑版预览的入口；电脑版仍是独立预览，不是本次 Android 正式包的一部分。

## 可选的手机状态分享

- 在「设置 → 能做的事 → 手机状态」中，分别选择是否让 TA 查询手机电量、充电状态和今日使用时长，默认关闭。
- 使用时长需用户手动授予系统使用情况访问权限，统计为今日亮屏且解锁时长估算，不含具体应用明细。
- 开启前会说明数据将发往该 TA 的模型接口；支持不调用模型的本机预览。仅私聊可用，可随时关闭，不增加后台监测或主动消息频率。

## 这次的小细节

- 表情包图片增加柔和圆角，保留动态图重播和长按操作。
- 深度思考从回复等待阶段就使用心跳：等待时「想一想」，思考中「在想」，结束后静止显示「想了想」。普通回复仍使用呼吸点；动效跟随系统动画设置，切到后台停止绘制。
- 完善思考中断、工具兼容、读物导入与阅读确认等异常处理。

聊天里的书架衔接沿用「设置 → 能做的事 → 回想世界」开关；阅读时的相关读书偏好沿用「记忆」开关。

经期记录、任意 PDF 分卷的手动归组，以及严格锁定其他应用的专注模式，仍留在后续计划。本版没有加入。部分设备的主动消息触发与后台提醒问题仍需继续观察和优化。
